AUTOMATION

自动化配置

验证码接收、授权处理、自动续期和后台运行。

入口：自动化配置
01验证码接收三种方式

在“自动化配置 → 短信验证码接收”选择来源。浏览器和弹窗仍支持手动输入，先获取到的验证码生效。

  1. Windows 手机连接：完成手机配对并开启通知同步，保持蓝牙和通知权限。
  2. 邮箱转发（IMAP）：开启邮箱 IMAP，使用授权码或应用专用密码，不要填写网页登录密码。
  3. Android SmsForwarder：允许读取短信、后台运行、自启动和忽略电池优化，测试“短信 → 邮件 → 工具捕获”链路。

邮件主题需与配置完全一致，推荐先点击“测试邮箱连接”。

02授权与内置浏览器处理流程
  1. “立即处理授权”会根据远端状态执行首次授权或续期。
  2. 模型配置完整时优先自动识别图形验证码，失败后转人工验证。
  3. 浏览器进度卡展示当前阶段；授权成功后远端列表会即时更新，无需刷新。
03自动续期与后台运行可选
  1. 自动化选项默认关闭；开启“自动续期”后按设置周期检查授权，每天 02:00–08:00 不执行自动续期，手动处理不受影响。
  2. “自动连接”负责 VPN 自动拨号，与自动续期相互独立。
  3. 开启“开机自启”后，Windows 登录时程序可静默进入托盘；“关闭时托盘”开启后，关闭窗口才会隐藏到托盘。
NETWORK

网络代理配置

VPN 连接、订阅节点、本地规则和流量分流。

入口：网络代理
01VPN 配置与凭据连接必需
  1. 在“VPN 配置”新增、编辑或删除 PPTP、L2TP、IKEv2 连接。
  2. 新增时可填写账号密码；L2TP 预共享密钥也可在同一弹窗配置。
  3. 没有工具凭据时点击“连接”，会先打开凭据弹框，不会提交空密码。
  4. 错误 691 通常表示凭据错误或授权到期，请在“凭据”中更新后重试。
02订阅、节点与智能优选代理来源
  1. 在“订阅”添加 URL，选择下载出口、节点策略和自动更新间隔；间隔可在关闭自动更新时预先设置。
  2. 在“节点”筛选、测速并选择实际节点；智能优选按地区顺序故障转移。
  3. 新增智能优选地区时，优先线路关键词默认为空，应按当前订阅的命名特征手动填写。
03规则与流量模式分流控制
  1. 规则模式按域名规则匹配，未命中时使用默认出口；全局模式仅使用 MATCH。
  2. 本地规则默认包为 cn-direct-v1，也可在“规则”中切换为其他规则包。
  3. 系统代理模式始终保护 localhost、回环、私有网段和本地域名；规则顺序为 bypass → user → builtin → MATCH。
04故障处理连接异常
  1. 网络波动会退避重试，配置、证书或系统服务错误会暂停自动重试并提示处理建议。
  2. 连接长时间卡住时，在总览使用“修复 VPN 服务”，并按 Windows UAC 提示操作。
  3. 同时连接多条 VPN 时，留意默认路由和网段重叠风险。
01选择短信验证码接收方式二选一

前往“自动化配置 → 短信验证码接收”选择一种来源。无论选择哪种方式，浏览器和工具弹窗中的手动输入都会保留。

方式 A：Windows 手机连接（蓝牙）

  1. 电脑打开“设置 → 蓝牙和设备 → 移动设备”，或直接打开“手机连接”App，并按引导配对 iPhone。
  2. 两端登录同一微软账号并扫码配对，开启通知同步，保持蓝牙连接。
  3. 手机收到短信时，确认 Windows 右下角能弹出同款通知；出现通知即代表工具可以自动捕获。
  4. 通知被清除或过期后不可回溯；工具使用实时捕获，不读取历史短信。

方式 B：iPhone 快捷指令邮箱

  1. 先在邮箱网页端开启 IMAP，生成授权码或应用专用密码；它不是网页登录密码。建议使用专用邮箱。
  2. 在 iPhone“快捷指令 → 自动化”中新建“信息”自动化，“信息包含”填写“超星学习通”，并选择立即运行。
  3. 添加“发送电子邮件”动作：收件人填写接收邮箱，主题固定为“超星验证码”，正文选择快捷指令输入。
  4. 展开邮件动作并关闭显示撰写表单；首次后台发送如询问权限，请允许快捷指令发送邮件。
  5. 在软件“自动化配置”选择“邮箱转发（IMAP）”，选服务商并填写账号、授权码。主题必须与快捷指令完全对应，然后保存并点击“测试邮箱连接”。
  6. 软件使用 SSL 只读拉取流程启动后到达的新邮件，不依赖邮件未读状态，也不会把邮件标为已读。

方式 C：Android SmsForwarder 邮箱转发

  1. 从项目官方 GitHub Releases 下载并安装 pppscn/SmsForwarder；安装前请自行确认来源和所需权限。
  2. 首次打开后授予读取短信权限，并按系统提示允许后台运行、忽略电池优化。部分品牌还需开启自启动、后台高耗电权限，并在最近任务中锁定 App。
  3. 进入“发送通道 → ＋ → 邮箱”，QQ 邮箱填写：SMTP 服务器 smtp.qq.com、端口 465、开启 SSL；发件账号填写 QQ 邮箱，密码填写邮箱授权码，收件人可以填写同一邮箱。
  4. 进入“转发规则 → 短信”，设置内容包含“超星学习通”（也可以按发件人过滤），发送通道选择刚创建的邮箱通道。
  5. 邮件标题固定填写“超星验证码”，正文填写 SmsForwarder 提供的短信正文占位符，例如 {短信内容}。占位符名称以当前 App 版本显示为准。
  6. 电脑端无需安装额外脚本：在“自动化配置”选择“邮箱转发（IMAP）”，填写同一邮箱的 IMAP 信息，并保持主题为“超星验证码”。保存后先点击“测试邮箱连接”。
  7. 用测试短信确认“手机收到短信 → 邮箱收到转发邮件 → 授权流程取得验证码”完整链路。若锁屏后失效，优先检查 SmsForwarder 的自启动、后台权限和电池优化设置。

常见问题：iPhone 弹出邮件编辑页说明“显示撰写表单”未关闭；Android 邮件未发出时检查转发规则、SMTP 授权码和后台保活；邮件已到但软件未捕获时，核对固定主题、IMAP 是否开启以及授权码是否有效。

02VPN 配置与凭据连接必需
  1. 可直接在“VPN 配置”中新增、编辑或删除 PPTP、L2TP、IKEv2 连接，无需先进入 Windows 设置。
  2. 新增时可同时填写登录凭据；L2TP 使用预共享密钥时也可在同一弹窗中填写。
  3. Windows 设置中保存的 VPN 密码不会暴露为明文；首次接管已有 VPN 时，需要在本工具中补录一次账号密码。
  4. 没有工具凭据时直接点击“连接”，软件会在拨号前停止并自动打开凭据弹框，不会提交空密码或弹出 Windows 登录窗口。
  5. 新增或补录账号密码时只保存到工具并同步 Windows，不自动拨号、不启动网页授权；随后点击“连接”才会执行远端认证。
  6. 错误 691 通常表示凭据错误或授权到期；若超星更换了 VPN 密码，请在“凭据”中更新。
03授权、验证码与内置浏览器自动化
  1. “立即处理授权”会根据远端状态，对未激活项目执行首次授权，对已有项目执行续期。
  2. 模型配置完整时优先自动识别；未配置或配置不完整时会跳过 AI，直接弹出人工验证。
  3. 自动识别多次未通过也会转为人工点击；程序在托盘时会自动恢复主窗口并提醒。
  4. 短信验证码按“自动化配置”中选择的来源捕获；也可以在浏览器或工具弹框中输入，先获取到的方式生效。
  5. 浏览器左下角展示真实进度；进度卡可收起，网络请求抽屉可查看 fetch/XHR 请求与响应。
  6. 接口返回成功后，远端列表会立即显示“已授权/续期完成”和成功提示；无需刷新，避免会话页面跳回登录。
04自动连接与日常使用可选
  1. “自动连接”默认关闭；关闭时仍可在总览中手动连接 VPN，授权处理不受影响。
  2. “默认 VPN”只决定总览快捷入口和自动重连；其它 VPN 可在配置页直接连接或断开。
  3. 已有连接时连接另一条，可选择“切换连接”或“同时连接”；并行连接后工具会提示默认路由和网段重叠风险。
  4. “自动续期”会按设置周期检查并更新网页授权，与 Windows VPN 的自动拨号策略相互独立。
  5. 网络波动类错误会按 5～30 分钟退避重试；配置、证书或本机服务错误会暂停自动重试，并在总览显示处理建议。
  6. 修改 VPN 配置、更新凭据、续期成功或完成服务修复后，暂停状态会自动解除。
  7. 连接长时间卡住时，可在总览右侧使用“修复 VPN 服务”，并允许 Windows UAC 授权。
05开机自启与分发高级
  1. 在总览的“自动化策略”中开启“开机自启”；下次登录 Windows 后程序会静默进入托盘。
  2. 自动化选项默认关闭；开启“关闭时托盘”后，点击主窗口关闭按钮才会隐藏到托盘。
  3. 分发时压缩整个工具文件夹；对方需使用 Win10/11、Edge WebView2，并自行填写本机配置。
