# 自动续期静默时段

- 日期：2026-09-09
- 功能：自动续期调度
- 分支：main

## 需求概述

自动续期不在本地时间凌晨 2:00（含）至早上 8:00（不含）期间启动。

## 关键设计

- 仅限制后台自动续期；用户点击“立即处理授权”仍可手动执行。
- 到达续期时间但处于静默时段时保留到期状态，8:00 后下一次调度自动领取任务。
- 使用本机本地时间判断边界，覆盖 02:00、07:59、08:00 和 01:59。
