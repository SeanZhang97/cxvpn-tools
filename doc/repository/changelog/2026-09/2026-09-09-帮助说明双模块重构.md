# 帮助说明双模块重构

- 日期：2026-09-09
- 功能：帮助说明
- 分支：main

## 需求概述

按当前软件能力重新组织帮助内容，拆分自动化配置与网络代理配置两类使用场景。

## 关键设计

- 增加帮助首页引导，明确账号、自动化、VPN、代理的推荐配置顺序。
- 自动化配置模块覆盖验证码接收、授权浏览器、自动续期与后台运行。
- 网络代理配置模块覆盖 VPN 凭据、订阅节点、智能优选、规则模式和故障处理。
- 保留折叠阅读方式，减少一次性展开的内容密度；旧帮助内容暂存为隐藏兼容结构，便于后续继续补充。

- `ui/style.css`
