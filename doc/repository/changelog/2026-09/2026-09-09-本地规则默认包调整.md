# 本地规则默认包调整

- 日期：2026-09-09
- 功能：路由规则默认配置
- 分支：main

## 需求概述

新安装或缺少明确规则包配置时，默认使用 `cn-direct-v1`。

## 关键设计

- 新安装默认配置和路由默认配置统一改为 `cn-direct-v1`。
- schema 2 及以上但缺少规则包字段的配置补全为 `cn-direct-v1`。
- schema 1 及更早的旧配置仍保持 `off` 迁移策略；已有明确的 `local-direct-v1` 选择不会被覆盖。

## 涉及文件

- `core/config.py`
- `core/routing.py`
- `tests/test_routing_schema.py`
