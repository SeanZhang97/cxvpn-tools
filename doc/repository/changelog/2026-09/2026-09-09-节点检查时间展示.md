# 节点检查时间展示

- 日期：2026-09-09
- 功能：节点工作台
- 分支：main

## 需求概述

优化节点卡片信息，并显示每个节点最近一次测速或健康检查时间。

## 关键设计

- 节点卡片新增“上次检查：MM-DD HH:mm:ss”。
- 未产生检测结果时显示“上次检查：未记录”。
- 首选节点下拉选项同步显示最近检查时间。
- 时间来自节点快照和运行态健康检查的 `tested_at`，不会把订阅拉取时间误当作节点检查时间。
- 运行态只有存在真实健康检查历史时才标记为已测速，避免切换节点后将默认 `alive` 状态误显示为“可用 / 无延迟”。
