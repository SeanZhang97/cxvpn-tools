# 配置损坏恢复

- 日期：2026-09-10
- 功能：配置文件损坏时自动恢复
- 分支：main
- 概述：修复异常退出或写入中断后配置读取静默回落为空配置，以及 Windows 系统代理启用后的注册表回读竞态。
- 涉及文件：`core/config.py`、`core/routing.py`、`tests/test_routing_commit.py`、`tests/test_routing_schema.py`
- 设计：保存配置前生成 UTF-8 原子备份 `config.json.bak`；读取主配置失败时回退到备份；系统代理启用后仅对已确认的本地端口补写 `ProxyEnable`，并在有界期限内回读确认。
- 验证：配置提交与路由 schema/reliability 定向测试，75 项通过。
- 注意：建议定期使用设置页的配置备份功能；备份文件与主配置位于 `%LOCALAPPDATA%\\CXVPNTools`。
