# 网络代理状态语义与可读性优化

- 日期：2026-09-01
- 功能名：网络代理生效配置、草稿提示与控制面可读性优化
- 分支：非 Git 工作区

## 需求概述与问题根因

网络代理首页只展示已保存配置，高级分流页可以同时保留未保存草稿。原界面仅用一句“有未应用修改”
提示差异，用户无法快速判断点击“开启代理”后采用已保存配置还是当前草稿；确认框也没有再次说明
这一边界。代理与节点控制面还大量使用 9.5～11px 的低对比度次要文字，在高分辨率窗口中辨识成本
较高，并且没有适配系统“减少动态效果”偏好。

## 关键设计

- 网络代理首页出现未保存草稿时，增加常驻提示卡，明确首页以已保存配置为基线，当前流量模式会在
  开启时应用，其他草稿不会自动包含，并提供返回高级分流的快捷操作。
- 代理关闭时直接展示下次开启将采用的接管方式、规则模式和默认出口；存在草稿时同步说明草稿不会
  自动生效。
- 开启代理确认框再次展示本次生效配置；若存在未保存草稿，明确要求先取消并保存草稿才能应用。
- 提高网络代理首页、节点卡、测速摘要和快捷入口中的关键状态字号与对比度，不改变现有布局结构。
- 增加 `prefers-reduced-motion: reduce` 适配，关闭非必要平滑滚动、动画和过渡。

## 影响范围

- 只改变网络代理与域名分流控制面的说明和视觉可读性，不改变配置持久化、代理启停、Mihomo、
  Windows 系统代理或 TUN 行为。
- 首页仍以已保存配置为基线，首页当前流量模式可在开启时覆盖对应字段；高级分流的其他草稿必须
  显式“保存并应用”后才进入运行配置。
