# 订阅地址明文展示

- 日期：2026-09-06
- 功能名：订阅 URL 展示方式
- 分支：main

## 需求概述

订阅编辑区原先默认遮蔽订阅 URL，需要点击眼睛按钮才能查看完整地址。用户要求在编辑订阅时直接
明文展示地址。

## 涉及文件

- `ui/routing.js`
- `tests/test_ui_polish.js`
- `doc/repository/knowledge/modules/Windows统一域名分流.md`

## 关键设计

- 订阅 URL 输入框固定使用普通文本类型，并移除该字段的显隐按钮。
- 为 URL 输入框保留独立 class，新建订阅后仍自动聚焦该字段。
- 仅改变编辑界面的可见性；日志脱敏、诊断包和配置备份保护逻辑保持不变。

## 影响范围

- 订阅卡展开后的 URL 输入与新建订阅后的输入焦点。
- 不改变订阅保存、下载、预览、更新及后端校验逻辑。
