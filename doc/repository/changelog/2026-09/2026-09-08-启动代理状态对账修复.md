# 启动代理状态对账修复

- 日期：2026-09-08
- 功能：重启后 Windows 系统代理状态恢复与残留清理
- 分支：main

## 问题

异常重启或进程被强制结束后，Windows 手动代理可能仍指向 CXVPN 的 `mixed-port`，而持久化配置已经是关闭状态，导致页面显示“代理未开启”但系统代理仍处于开启。

## 修复

- 启动后台复核持久化 `routing.enabled`、原生服务运行状态和 Windows 实际代理端点。
- 配置应启用时，恢复 CXVPN 系统代理接管并确认核心运行。
- 针对部分 Windows 环境中原生服务能写入代理地址但当前会话 `ProxyEnable` 回读仍为 0 的情况，增加交互进程的启用位补写和有界回读。
- 配置已关闭但代理精确指向当前 CXVPN `mixed-port` 时，关闭残留接管后继续恢复待机核心。
- 只处理 CXVPN 自身端点，不修改第三方代理软件的代理设置。
