# 运行日志与出口探测优化

- 日期：2026-09-08
- 功能名：运行日志与网络出口采集可靠性优化
- 分支：未知

## 需求与根因

运行日志分析显示，网络出口每 5 分钟产生大量重复成功日志；海外出口失败率高于
国内出口，且两个 Cloudflare 探测地址串行尝试会放大超时。运行日志同步打开文件，
VLM 请求最长等待 60 秒，连续故障时会重复占用授权流程；多行模型回复还会破坏日志
的逐行解析。

## 关键变更

- 海外 Cloudflare 探测改为并发竞速，并对同一 IP 的位置/运营商结果缓存 15 分钟。
- 网络出口部分失败时增加 5 分钟起、最长 30 分钟的指数退避；总览页定时刷新间隔与
  后端缓存窗口对齐，离开总览页后不再触发自动探测。
- VLM 默认请求超时调整为 35 秒；连续 3 次网络或 HTTP 失败后熔断 120 秒，成功后
  自动恢复，仍保留人工验证码兜底。
- 运行日志统一将换行转义为单行事件；`run.log` 使用有界后台写入器和 `.1/.2`
  文件轮转，退出时有限等待队列排空。
