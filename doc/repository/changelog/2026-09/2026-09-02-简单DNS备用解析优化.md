# 简单 DNS 备用解析优化

- 日期：2026-09-02
- 功能名：简单 DNS fallback
- 分支：main

## 问题根因

简单 DNS 模式把 Cloudflare `1.1.1.1` 和 Google `8.8.8.8` 的 DoH 地址硬编码为 fallback。
当前网络无法直连这两个地址的 443 端口，Mihomo 因此反复记录 `dial PHYSICAL` 超时警告；
主 DNS 成功时业务仍可能正常，导致不同机器因缓存和请求时机不同而表现不一致。

## 涉及文件

- `core/routing.py`
- `ui/index.html`
- `tests/test_routing_schema.py`
- `tests/test_ui_routing.js`

## 关键设计

- 简单模式的 fallback 复用默认 `proxy_server_nameserver`，统一为 AliDNS 与 DNSPod DoH。
- 保留主 nameserver、`fallback-filter`、fake-IP、`respect-rules` 和高级模式自定义行为。
- 更新简单模式摘要及高级 DNS 输入示例，避免继续引导填写当前网络不可达的地址。
- 未新增依赖、网络协议或配置字段。

## 影响范围

新生成的简单 DNS Mihomo 配置不再直连 `1.1.1.1:443` 和 `8.8.8.8:443`；高级 DNS 模式中
用户显式配置的地址不受影响。
