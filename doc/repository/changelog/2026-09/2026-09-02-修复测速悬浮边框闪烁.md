# 修复测速悬浮边框闪烁

- 日期：2026-09-02
- 功能名：节点测速卡片悬浮状态
- 分支：main

## 问题根因

节点测速期间前端每 250ms 轮询一次任务进度，每次进度更新都会销毁并重建全部节点卡片。
鼠标停留在卡片上时，新元素会反复重新触发 hover 边框过渡，表现为选中边框持续闪烁。

## 涉及文件

- `ui/routing.js`
- `tests/test_ui_routing.js`
- `doc/repository/knowledge/modules/Windows统一域名分流.md`

## 关键设计

- 以节点名作为页面内稳定键，测速进度刷新时复用已有卡片外层 DOM。
- 只替换卡片内部状态内容，并按当前筛选和排序结果精确移动、增删卡片。
- 清理复用卡片中过期的 `aria-current`，保持选中语义与当前状态一致。

## 影响范围

仅影响节点工作台的卡片渲染；测速进度、筛选、排序、选点及后端任务不变。
