# 代理工作区视觉与速率趋势

- 日期：2026-09-08
- 分支：main
- 类型：UI 视觉与交互优化

## 需求概述

统一网络代理、订阅、节点、规则和连接页面的视觉语言，为主要页面与卡片补充自绘线性图标，并在网络代理首页增加实时上下行速率趋势图，提升状态识别和浏览效率。

- `ui/index.html`
- `ui/style.css`

- `tests/test_ui_proxy.js`
- `tests/test_ui_routing.js`
- `doc/repository/knowledge/modules/Windows统一域名分流.md`

## 关键设计

- 代理首页改为“连接状态 → 配置摘要 → 流量观测 → 当前连接”的阅读顺序，主连接卡使用更强的层级、状态色和操作按钮，订阅与节点行改为可点击的独立信息块。
- 代理状态图标区域沿用原有 SVG 徽标与动画，仅恢复其原始尺寸和透明背景，不叠加新的外圈装饰。
- 订阅概览和服务状态指标补充订阅、节点、缓存、连接、上下行等线性小图标，沿用现有蓝紫/青色状态色和卡片圆角。
- 订阅概览和流量策略采用双列紧凑卡片，服务状态改为横向宽卡：左侧展示六项关键指标，右侧展示上下行趋势，避免内容稀疏时出现大块空白。
- 订阅、节点、规则和连接工作区统一卡片底色、顶部强调线、选中态和悬浮态；节点卡与规则行提高可读字号和点击反馈，连接页指标和筛选工具保持同一层级。
- 服务状态卡保留过去 60 秒上下行趋势图。前端复用现有遥测事件维护时间窗口，按采样窗口共同缩放两条曲线，断开或重连时清空历史并归零。
- 图表使用 SVG 绘制，不新增第三方依赖；文本速率继续保留，图表同时维护动态无障碍说明。
- 趋势图增加透明悬停命中层、时间竖线和上下行节点标记；鼠标移动或图表获得焦点时显示采样时间、当前节点、上行与下行速率。
- 悬停提示改为跟随采样点上下自适应定位，增加指向采样点的细箭头、边缘夹紧和更紧凑的数值层级，避免遮挡高峰线段。
- 修正 Tooltip 在基线附近因高度测量过早而被放到图表下方的问题；现在先填充内容再测量，并将完整提示卡限制在图表容器范围内。
- 节点测速状态统一以当前运行态代理组为优先来源；运行组测速完成后回写 `provider_nodes` 快照，并刷新已打开的智能优选首选节点下拉框，避免卡片与下拉框出现不同延迟或“未测速”状态。
- 纯浏览器预览在 `DOMContentLoaded` 阶段预绑定导航，WebView2 就绪后继续使用完整绑定；浏览器可见性同步在无后端桥接时安全跳过。

## 影响范围

- 仅影响网络代理、订阅、节点、规则和连接工作区的呈现与前端遥测可视化。
- 不改变代理启停、订阅更新、节点选择、规则保存和连接关闭等业务行为。

## 注意事项

- 图表采样频率沿用后端遥测事件频率，按采样时间裁剪最近 60 秒的数据。
- 悬停提示只展示当前页面已选节点和去标识化速率采样，不新增网络请求或敏感信息。
