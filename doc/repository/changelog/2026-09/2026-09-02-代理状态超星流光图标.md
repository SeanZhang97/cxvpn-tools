# 代理状态超星流光图标

- 日期：2026-09-02
- 功能名：网络代理状态图标优化
- 分支：main

## 需求概述

网络代理首页原状态图标采用“圆形边框内放置方形应用图标”的结构，品牌元素层级割裂，且无法表达代理流量从接管到生效的动态过程。本次基于超星原始 Logo，保留右上星星及下方四条曲线，去掉大面积白色填充，改为由完整双轨网络圆环包裹的纯线框标记，并加入圆环循环流光、底部能量上升、星星点亮和环形脉冲动画。

## 关键设计

- 最终确认稿中的超星标记经过透明化处理后拆分为完整线框、四条能量路径和星星三个同坐标 PNG 图层，避免用 CSS 或手绘 SVG 近似品牌轮廓。
- 外围使用独立的完整双轨网络圆环 PNG，基础层保持连续闭合，两个运动层以不同速度和方向旋转，节点与高亮弧随轨道移动。
- 代理运行时由 `proxy.js` 为 `#proxy-orbit` 切换 `is-active`；圆环持续运转，内部路径按 6.4 秒周期从底部充能，星星点亮后触发一次向外扩散的圆环脉冲。
- 流光扫描使用柔和遮罩沿品牌路径移动，避免硬 `clip-path` 形成水平截断；资产脚本负责黑底透明化、有效像素裁切和同坐标图层生成。
- 异常或未知状态降低饱和度；未运行状态保留克制的静态轮廓，不播放代表已接管流量的动画。
- 全局 `prefers-reduced-motion` 规则会把动画降级为单次静态终态，避免持续运动影响可用性。

## 影响范围

- 仅影响网络代理首页状态卡片左侧图标及其运行状态表现。
- 不改变代理启停、配置、遥测、订阅或节点选择逻辑。
- 新增 PNG 资源会随 `ui/` 一并进入 PyInstaller 产物。

## 注意事项

- 动画仅在后端状态确认为 `running` 时启用，不能用排队或启动中状态冒充代理已开启。
- 后续替换品牌资产时，应保持圆环和三个 Logo 图层的画布尺寸、圆心与注册坐标一致，否则圆环包裹、星星点亮和路径流光会错位。
