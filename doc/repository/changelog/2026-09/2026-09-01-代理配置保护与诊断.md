# 代理配置保护与诊断

- 日期：2026-09-01
- 分支：main
- 功能：系统代理绕过、配置备份恢复、应用历史与脱敏诊断

## 需求概述

继续实施参考 Clash Verge Rev 后确认的 P1 优化：为代理配置增加本地安全备份和差异恢复，支持
局域网、域名与进程绕过，保存最近有效配置并允许回退，同时提供不会泄露订阅、凭据和连接目标的
诊断导出。

## 问题根因

- 路由配置只有当前版本，误修改或应用失败后缺少可见的 last-known-good 回退入口。
- Windows 仅有固定的本地安全绕过，用户无法把指定域名或进程稳定固定到物理出口。
- 排障信息分散在应用日志、Mihomo 日志和原生服务状态中，直接复制原始内容存在泄露订阅 Token、
  Controller Secret 或连接目标的风险。
- 直接恢复完整 `config.json` 会同时覆盖启用状态和本机凭据，不适合作为安全的配置迁移流程。

## 关键设计

- routing schema 升级为 v3，新增 `system_proxy_bypass`。局域网/回环保持 Windows
  `ProxyOverride` 安全基线；自定义域名和进程生成最高优先级 `PHYSICAL` 规则，在全局模式下
  仍早于 `MATCH`。
- 备份采用带产品和版本标识的 JSON 封套，默认排除订阅 URL；无论选项如何，登录、VPN、邮箱、
  VLM、Controller 和自定义上游凭据都不导出。
- 恢复先校验文件和路由 schema，再返回不含候选配置的差异摘要；确认后保留当前凭据与代理启用
  状态，并复用现有服务应用、磁盘原子提交及失败回滚事务。
- 当前用户目录保存最近 12 次应用结果。成功记录可回退，失败记录仅保留摘要和脱敏错误；首次应用
  前自动记录当前有效配置作为基线。
- 诊断 JSON 只输出计数、模式、服务状态和最近脱敏日志；连接数据只保留活动/关闭数量及流量合计，
  不包含目标、进程路径、规则载荷或代理链。
- 概览页集中展示绕过配置和维护入口；恢复和回退均二次确认，配置历史列表使用项目统一深色滚动条。

## 影响范围

- 仅影响本地代理路由配置和本机导入导出，不访问云端备份服务，不增加第三方依赖。
- 旧 schema v1/v2 在加载时补全新字段；缺少版本的旧配置仍保持原有 TUN 和用户规则语义。
- 默认备份用于同机安全恢复；跨设备且未包含订阅 URL 时，新订阅需要手动补充地址。

## 注意事项

- 配置历史包含回退所需的完整路由配置，位于当前 Windows 用户目录，不通过 API 暴露详情。
- TUN 不读取 Windows `ProxyOverride`；如需在 TUN 下直连私有网段，应保留
  `local-direct-v1` 或 `cn-direct-v1` 内置规则包。
- 当前会话缺少 Windows 应用控制所需的 `node_repl`，未执行窗口截图级视觉检查；布局由 UI 结构、
  DOM 引用完整性、响应式 CSS 和发行首屏加载结果验证。
