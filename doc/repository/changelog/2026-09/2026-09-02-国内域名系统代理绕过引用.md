# 国内域名系统代理绕过引用

- 日期：2026-09-02
- 分支：main

## 需求概述

系统代理模式下，`cn-direct-v1` 只能在请求进入 Mihomo 后决定物理直连，浏览器仍会先连接本机
`mixed-port`。用户需要让国内域名在 Windows 系统代理入口直接连接，同时避免把规则包逐条复制到
手动绕过输入框形成重复配置。

## 关键设计

- routing schema 升级为 v7，`system_proxy_bypass` 新增 `include_cn_direct`，旧配置默认关闭，保持原有
  系统代理行为。
- UI 新增“国内域名不经过系统代理”开关，并显示规则包域名数、手动补充数和合并去重后的实际数量；
  原手动域名区域明确为“补充绕过域名”。
- “国内域名不经过系统代理”和“备份中包含订阅地址”统一使用左侧说明、右侧开关的紧凑设置行，
  去除悬空的原生复选框，并保留整行点击、键盘焦点和启用态反馈。
- 启用后从软件启动时加载的 `cn-direct-v1` 内存快照提取国内域名后缀，不重复读取文件；与手动域名
  合并去重后，通过现有配置事务交给原生服务生成 `ProxyOverride`。
- 该引用只改变 Windows 系统代理入口，不隐式扩展 TUN 的 Mihomo 规则；TUN 仍由本地规则包选择控制。
- 原生服务版本升级到 0.6.0，合并后域名上限调整为 2100，覆盖规则包 2000 条和手动补充 100 条的边界。
- 配置预检同步解析引用规则包并返回实际系统代理绕过域名数，规则包损坏时不会到应用阶段才失败。
- 国内直连采用两层策略：已知域名后缀写入 Windows `ProxyOverride`，完全不经过本机代理端口；
  其余进入 Mihomo 的流量在显式规则之后通过 `GEOIP,CN,PHYSICAL` 兜底，国外 IP 继续使用默认出口。
- 内置 `cn-direct-v1` 增加 `sslibrary.com` 与其 CNAME 所属的 `aichaoxing.com`。
- 打包固定校验过的离线 `Country.mmdb`，预检、原生服务安装和升级都复制并校验同一快照；不在后台
  下载或更新规则数据。
- 简易 DNS 改为国内解析优先、国外 DoH fallback，并使用 `fallback-filter` 按中国 IP 和异常地址段
  选择结果；保留高级 DNS 的用户配置语义。

## 影响范围

- Windows 系统代理 `ProxyOverride` 生成与快速启停恢复。

- 高级路由“系统代理绕过”交互。
- 简易 DNS 解析路径、Mihomo 规则顺序与原生服务运行数据安装。

## 注意事项

- `cn-direct-v1.txt` 仍只在软件启动时加载；修改文件后需重启软件并重新应用配置。
- `ProxyOverride` 只负责已知域名的系统代理入口绕过；`GEOIP,CN` 兜底位于 Mihomo 内部，显式用户
  规则和本地规则包仍具有更高优先级。
