# 订阅生命周期概览优化

- 日期：2026-09-01
- 功能名：网络代理首页订阅流量、重置与到期概览
- 分支：非 Git 工作区

## 需求概述与问题根因

网络代理首页原先只能看到订阅数、节点数和缓存状态。部分订阅会把剩余流量、下次重置和套餐
到期日编码为特殊节点名；这些可靠的本地快照数据已存在，但用户必须进入节点列表自行辨认，
容易错过低流量或临近到期状态。对比 Clash Verge 的订阅信息展示，首页缺少订阅生命周期摘要。

## 关键设计

- 只从当前目标订阅已持久化的安全节点快照中识别明确格式的“剩余流量”“下次重置”和
  “套餐到期”元数据；不读取或展示订阅 URL，也不为展示触发远程更新。
- 元数据缺失时整个摘要自动隐藏；公告和普通节点不会作为生命周期数据展示。
- 有总流量时按剩余比例判断提醒等级；没有总流量时只使用保守的绝对剩余量阈值。到期剩余
  30 天内提示、7 天内告警，不伪造总量、百分比或实时速率。
- 摘要使用真实文本 DOM 和 `aria-live` 状态语义，窄屏降为单列；所有值通过 `textContent`
  写入，避免外部节点名进入 HTML。

## 影响范围

- 只改变网络代理首页的前端只读展示，不修改订阅缓存、下载周期、Mihomo、system-proxy、TUN
  或 Windows 路由行为。
- 生命周期信息来自最近一次已保存快照，刷新时间仍由现有订阅管理流程决定。
