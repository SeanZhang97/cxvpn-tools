# Git 仓库初始化

- 日期：2026-09-01
- 功能名：GitHub 代码仓库初始化
- 分支：`main`

## 需求概述与问题根因

项目原目录不是 Git 工作区，且没有 `.gitignore`。直接初始化和提交会把用户
`config.json`、WebView 浏览数据、运行日志、本地缓存、Python 虚拟环境与打包产物一并
上传，存在凭据泄漏和仓库膨胀风险。

## 涉及文件

- `.gitignore`
- `doc/repository/changelog/2026-09/README.md`
- `doc/repository/knowledge/INDEX.md`
- `doc/repository/knowledge/common/Git仓库管理.md`

## 关键设计

- 排除本地用户配置、浏览器数据、运行日志、运行时状态、Python/Rust 缓存、打包产物和 IDE 文件。
- 保留 `runtime/routing` 中已锁定版本、SHA-256 和许可证的 Mihomo/WinSW 运行时，
  保证仓库克隆后仍具备打包依赖。
- 排除由 Rust 源码可重建的 `CXVPNRoutingHost.exe` 和 `routing-service/target/`。

## 影响范围

只影响 Git 跟踪范围与仓库初始化，不修改应用运行、配置读写或打包逻辑。

## 验证情况

- `git status --short --ignored` 和 `git check-ignore -v`：已确认 `config.json`、`.venv/`、
  `dist/`、`build_tmp/`、WebView/浏览器数据、运行时状态与 Rust `target/` 均未进入跟踪清单。
- 首次跟踪清单共 210 个文件、约 69.9 MB；最大两个文件为已锁定的 Mihomo/WinSW 运行时。
- Mihomo 与 WinSW 的 SHA-256 与 `runtime/routing/README.md` 记录一致。
- 待提交文本的私钥、GitHub/OpenAI Token、带凭据 URL、手机号和邮箱候选扫描已完成；
  命中内容仅为测试占位符、示例 URL、示例邮箱、Git SSH 地址与 Cargo 校验和。

## 注意事项

- `config.json` 为便携式用户配置，始终保持本地化，不得强制加入 Git。
- 提交新的运行时二进制前，必须同步版本、来源、SHA-256 和许可证说明。
