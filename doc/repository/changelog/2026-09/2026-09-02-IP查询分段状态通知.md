# IP 查询分段状态通知

- 日期：2026-09-02
- 功能名：网络出口刷新
- 分支：main

## 需求概述与问题根因

原实现虽然并发查询内网、公网出口和国外出口，但必须等待三路全部结束后才统一写入结果；
前端每 500ms 跨 pywebview 桥轮询缓存，因此快速完成的结果无法立即展示。

## 涉及文件

- `core/ip_info.py`
- `api.py`
- `ui/app.js`
- `tests/test_ip_info.py`
- `tests/test_ui_event_stream.js`
- `tests/test_ui_polish.js`
- `doc/repository/knowledge/modules/CXVPN管理器.md`

## 关键设计

- 三路任务仍使用线程池并发查询，但改为按实际完成顺序发布单项结果。
- 每项结果写入缓存后唤醒项目已有的 `wait_ui_state` 版本化状态订阅。
- UI 从状态快照的 `ip_info` 分段更新，不再每 500ms 轮询 `get_ip_info()`。
- 刷新过程中收到新的强制刷新请求时由后端合并排队，当前批次结束后补做一次。
- 沿用既有缓存、失败保留旧数据和五分钟过期策略，没有新增 WebSocket 或外部依赖。

## 影响范围

仅影响总览网络出口卡片的刷新与状态通知；IP 探测目标、网络出口策略和 VPN 状态订阅不变。
