# 智能优选地区关键词默认值

- 日期：2026-09-09
- 功能：节点智能优选地区配置
- 分支：main

## 问题根因

智能优选界面在新建策略或新增地区时，统一预填“高速专线”“IPLC”“IEPL”等线路关键词。这些关键词只适用于特定订阅，不能作为所有订阅的通用默认值。

## 修复内容

- 新建智能优选策略的地区保留为空的优先线路关键词。
- 新增地区不再自动添加订阅特征关键词。
- 已保存策略中的用户自定义关键词保持不变。

## 涉及文件

- `ui/routing.js`
