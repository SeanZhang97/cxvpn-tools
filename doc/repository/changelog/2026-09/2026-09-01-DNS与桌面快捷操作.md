# DNS 与桌面快捷操作

- 日期：2026-09-01
- 分支：main
- 功能：DNS 简单/高级模式、托盘快捷操作、全局快捷键与轻量模式

## 需求概述

继续实施 Clash Verge Rev 对照清单中的 P2：为普通用户提供稳定的推荐 DNS，为高级用户开放可验证
的 nameserver、fake-IP 和域名策略；把常用代理操作放入系统托盘；为高频用户增加可选全局快捷键
和低视觉/低采样开销的轻量模式。

## 问题根因

- 原界面直接展示四组 DNS 地址，没有推荐模式与高级配置边界，fake-IP 参数固定在生成代码中。
- 托盘只有打开和退出，启停、模式切换、选点及查看连接都必须恢复主窗口后逐层导航。
- 高频用户缺少跨窗口操作入口；完整动画、模糊和 0.5 秒状态采样在低资源环境下没有降级选项。

## 关键设计

- routing schema 升级为 v4。新配置默认 DNS 简单模式，旧 schema 自动迁移为高级模式以保持现有
  流量路径；切换简单模式不会删除高级草稿。
- 高级模式校验 DNS 地址协议和长度、fake-IP 保留地址池、排除域名、域名策略重复与数量上限；
  `redir-host` 不输出 fake-IP 运行字段。独立校验不访问网络，保存应用仍执行完整 Mihomo 预检。
- 托盘展开时从安全节点快照动态构造状态、模式和节点菜单；启停、模式切换与节点选择都复用
  路由原子事务，节点选择只接受当前持久化快照中的节点。所有耗时动作在后台线程执行。
- 全局快捷键固定且默认关闭，通过 Win32 `RegisterHotKey` 独立消息线程实现，不使用低级键盘钩子；
  只有 `Ctrl+Alt+P/M/C` 全部注册成功才启用。
- 轻量模式关闭动画、模糊和高成本阴影，把全局状态采样从 0.5 秒降低到 1.5 秒；事件触发唤醒、
  代理遥测和连接/日志页面生命周期不变。

## 影响范围

- 不新增第三方依赖，不改变原生路由服务或 IPC 协议。
- 全局快捷键默认关闭，不在用户未授权时注册系统按键。
- 托盘节点来源是本地脱敏快照，不会因打开菜单触发订阅更新或节点测速。

## 注意事项

- `respect-rules` 可能让高级 DNS 上游按规则再次选路；配置不当会形成解析环路，因此 UI 明确标记
  为高级选项并在保存时执行 Mihomo 预检。
- 快捷键被其它程序占用时保持设置为“期望启用”，但当前会话不注册任何一项，并显示冲突提示；
  关闭冲突程序后重新关闭并开启开关即可重试。
