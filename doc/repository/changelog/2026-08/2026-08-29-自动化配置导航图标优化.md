# 自动化配置导航图标优化

- 日期：2026-08-29
- 功能名：自动化配置导航图标重绘
- 分支：非 Git 工作区

## 需求概述与问题根因

侧栏「自动化配置」原滑杆图标更接近通用设置，无法直观表达验证码识别和自动执行流程。

## 涉及文件

- `ui/index.html`
- `tests/test_ui_polish.js`
- `doc/repository/knowledge/modules/CXVPN管理器.md`

## 关键设计

- 改为魔法棒与三组星芒组合，表达自动识别、智能处理和自动执行。
- 继续使用项目统一的 24 × 24 线性 SVG 体系，继承现有线宽、颜色、悬停和选中状态。
- 图标保持 `aria-hidden="true"`，导航文字继续作为可访问名称。

## 影响范围

仅影响侧栏「自动化配置」的图标外观，不改变页面导航、自动化配置或授权流程。

## 验证情况

- `node tests/test_ui_polish.js`：验证新图形路径存在、旧滑杆路径移除及导航图标数量不变。
- `uv run --with pyinstaller python build.py`：打包成功；`config.json` 打包前后 SHA-256 与大小一致，产物 `index.html` 哈希与源码一致。
- 新版实际窗口抽查：19px 默认态和选中态下魔法棒、星芒轮廓均清晰，颜色与其它导航图标一致；仅切换页面，未修改配置。

## 注意事项

图标使用内联 SVG，不新增图片资源或第三方依赖。
