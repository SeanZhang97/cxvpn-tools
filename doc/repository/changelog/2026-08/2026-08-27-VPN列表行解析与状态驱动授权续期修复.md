# VPN 列表行解析与状态驱动授权/续期修复

- 日期: 2026-08-27（第四版）
- 功能名: 登录进入「选择 VPN」页后按行状态执行授权/续期
- 分支: 非 Git 工作区

## 需求与根因

用户实测: 验证码通过、登录进入「选择 VPN」弹框后流程停住, 不执行
下一步。对照站点 vpnLogin.js 与运行日志定位两个根因:

1. **列表非表格**: 站点用 layui div 行渲染 (`#vpnInfoList
   .layui-form-item`, 复选框 `name="batchVpnId"` value=id, 状态 label
   `id^=status`), 旧 `_read_vpn_rows` 用 `cb.closest('tr')` 取行文本 →
   永远空串 → 目标 VPN 匹配不到 → 状态判定/接口调用分支从不执行。
2. **大小写敏感匹配**: 配置 `中经云pptp` (小写) vs 页面 `中经云PPTP`
   (大写), JS 桥 `:has-text` 为大小写敏感 includes → 兜底分支也找不到
   行 → 直接返回失败, 表现为"进入页面后无动作"。

## 涉及文件

- `core/web_flow.py` (行解析重写 + 归一化匹配 + 状态驱动兜底点击)

## 关键设计

- `_read_vpn_rows` 按真实 DOM 读行: 行 div 内取复选框/hidden value=id、
  无 id 的 label=名称、`label[id^="status"]`=状态 (已授权/未授权/未激活),
  `need_auth = /未授权|未激活|激活/`; 旧表格结构保留兼容兜底。
- `_norm` 归一化 (去空白+小写) 匹配配置与页面名称, 解决大小写不一致。
- 动作按状态决定 (用户要求): 未授权/未激活 → `POST /vpn/batchLoginVpn`
  (授权); 已授权 → `POST /vpn/batchReLoginVpn/addTime` (续期); 日志打印
  行状态便于核对。
- `_list_ready` 统一列表就绪判定 (行复选框/行 div/批量按钮/弹框标题),
  替换原 `text=批量续期` 单信号 (全部未激活时批量按钮容器被站点隐藏会
  误判未登录/未跳转)。
- 页面点击兜底改为页内 JS 按名称归一化定位行 div, 再按该行状态精确
  click 对应按钮 (授权/激活 或 续期), 不再用 `tr:has-text`/`text=` 模糊
  命中 (旧实现会误点状态 label「未授权」或首行按钮)。

## 影响范围与验证

- py_compile 过; 已强制关闭运行中实例并重打包。
- 待实测: 未授权行自动走 batchLoginVpn、已授权行走 addTime, 日志应见
  「目标 VPN 状态=…, 调授权/接口续期」。
