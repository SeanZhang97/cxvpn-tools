# 续期点击命中修复与短信弹窗可关闭

- 日期: 2026-08-27
- 功能名: 登录「获取验证码」点击命中修复 + 手动短信弹窗关闭按钮
- 分支: 非 Git 工作区

## 需求与根因

1. 点「立即续期」后内嵌面板打开登录页、手机号已填, 但图形验证码弹窗
   永不出现。根因为内嵌 shim 选择器引擎两处缺陷 (假手机号真实站点探针
   定位, 点击落点经 document capture 与按钮监听计数证实):
   - `pick` 同长度取文档序靠前者: `text=获取验证码` 的外层容器
     `layui-col-xs3` 的 textContent 恰也 5 字且父节点序先, 命中外层容器;
     点容器事件向上冒泡, 到不了 `#vpnSmsCodeBtn` 的 jQuery handler,
     静默空操作。这也解释真机手动 `$('#vpnSmsCodeBtnText').trigger('click')`
     有效 (命中最内层)。
   - `vis()`/`_popup_visible` 把验证码 SDK 预插的 0×0 隐藏 `#eject` 容器
     (display=block, 空矩形 getClientRects 长度也为 1) 当"可见", 弹窗判定
     失真。
2. 手动短信验证码弹窗 (#smsmodal) 只有「提交」, UI 侧无法主动关闭,
   只能等后端流程结束 (最长 sms_timeout=120s) 才自动隐藏。

## 涉及文件

- `core/browser_win.py`: `pick` 同长度取最内层 (<=, 文档序靠后);
  `vis` 增加空矩形尺寸门槛 (宽高 ≥1)。
- `core/captcha_handler.py`: `_popup_visible` 增加真实尺寸判定
  (与 shim vis 一致); 新增 `_click_retry_if_blocked` 并接入 `_refresh`
  与两循环顶部 (连败「失败过多，点此重试」态普通刷新无效, 点横幅重置)。
- `core/web_flow.py`: 点击前等 `window.captchaIns` 就绪 (≤15s) + 点击后
  以「弹窗出现」为准重试 3 次 (防御性兜底)。
- `api.py`: 新增 `dismiss_sms_ui()` (UI 主动关弹窗, 后台捕获不受影响)。
- `ui/index.html` / `ui/app.js`: #smsmodal 增加「关闭」按钮与文案。
- 探针: `probe_embed_click.py` (假手机号端到端, 含 Playwright→PageShim
  同语义适配 PWShim)、`probe_click_target.py` (点击落点定位)、
  `probe_retry_state.py` (主动触发失败态验证复位)、
  `probe_disabled_click.py`、`probe_cx_dbg.py`。
- 知识库 `modules/CXVPN管理器.md` 同步选择器引擎语义。

## 关键设计

- 选择器语义对齐 Playwright: 可见匹配中取文本最短、同长度取最内层
  (文档序靠后), 保证点击命中带 handler 的元素而非同文外层容器。
- 可见性统一加尺寸门槛: 站点 SDK 预插 0×0 #eject (display=block),
  仅判 display/rects 数量会误判弹窗已出现。
- 连败失败态: 站点把弹窗底部换成「失败过多，点此重试」横幅后
  `.cx_refresh` 无效; `_refresh` 先检测横幅 (text=点此重试) 点击重置,
  attempt/人工循环顶部先复位再取图, 避免解旧图浪费尝试次数。
- 就绪等待+点击重试为防御性增强: 覆盖冷启动 SDK 异步加载场景;
  重试以带尺寸门槛的 `_wait_popup(#eject)` 为判据。
- 关闭短信弹窗仅置 `_sms_ui=False`: 自动捕获/页内手动输入仍并行生效;
  下次流程 `sms_show(True)` 递增 id 后弹窗重弹 (poll 按 id 去重)。

## 影响范围与验证

- 影响未登录态登录触发段 (内嵌面板与探针同语义) 与短信弹窗 UI;
  已登录态接口续期路径不变。
- 探针验证 (假手机号, add_init_script 注入 INSTALL_JS, 全程 cx.q/cx.act):
  修复前 clicklog=0 弹窗不出现 (复现用户症状); 修复后一次点击
  clicklog=1 弹窗出现, 图标点选第 3 次通过, 抓包见站点带 validate 调
  `GET /vpn/getSmsCode` (假号 400 为正常业务响应)。
- 失败态探针: 4 轮错误点击触发「失败过多」横幅, `_click_retry_if_blocked`
  检测点击后横幅消失、出新图 (新 sprite ≠ 旧图)。
- 真机内嵌面板待用户下次「立即续期」确认。

## 注意事项

- `<=` 同长度取内层对其余 text= 选择器 (如 批量续期) 同样生效, 与
  Playwright 最小元素语义一致, 探针未见回归。
- 关闭短信弹窗后若想再手动输码: 可直接在页面验证码输入框输入, 或等
  下次流程弹窗重开。
