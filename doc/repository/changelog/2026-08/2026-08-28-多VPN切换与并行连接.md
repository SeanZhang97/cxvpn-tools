# 多 VPN 切换与并行连接

- 日期: 2026-08-28
- 功能名: 默认 VPN、逐行连接、多连接总览与路由冲突提示
- 分支: 非 Git 工作区

## 需求概述与问题根因

用户平时主要使用一个 VPN，偶尔切换另一条或同时连接多条。旧实现虽然能读取多个
Windows VPN 配置，但连接控制只围绕单个 `vpn_name` 和单个 `connected` 布尔值：
列表不能直接连接，切换需要先设目标再返回总览；目标切换后旧缓存还可能短暂显示为
新目标已连接，也无法表达多个活动连接。

## 关键设计

- `vpn_name` 保留兼容但改称“默认 VPN”，自动连接只恢复默认项；手动操作使用按名称
  API，不再把其它 VPN 排除在控制范围外。
- worker 缓存 `connections[]`、连接时长和 `route_conflicts[]`；兼容字段
  `connected` 只表示默认 VPN 是否在线，避免切换默认项后状态串线。
- VPN 列表增加逐行连接/断开与“设为默认”；总览展示全部活动连接、地址、会话时长、
  默认路由、逐条断开和断开全部。
- 已有其它连接时，连接与凭据验证都必须选择“切换连接”或“同时连接”。切换模式先
  逐条断开现有 VPN；并行模式保留连接，完成后检查多个默认路由和网段重叠。
- 系统查询一次性合并 `Get-VpnConnection`、`Get-NetIPAddress`、`Get-NetRoute`，
  UI 高频轮询只读 worker 内存，避免恢复旧版启动假死问题。
- RAS 状态名称改为大小写无关的精确匹配，避免相似名称互相误判；PowerShell 参数统一
  使用单引号字面量转义，VPN 类型使用固定白名单。

## 影响范围

- Windows VPN 手动连接、断开、凭据验证和自动重连。
- 总览连接卡、VPN 配置表格及帮助说明。
- 不改变超星授权批处理、浏览器自动化、短信或验证码流程。

## 注意事项

- 路由详情按 VPN 名称与 Windows 接口别名精确关联；若第三方 VPN 驱动使用不同接口
  别名，连接仍可管理，但地址和路由详情可能显示为由 Windows 管理。
- 同时连接能否访问各自网段最终仍由 Windows 路由优先级、服务端策略和网段规划决定。
