# 内置浏览器原生化与验证码通过判定修复

- 日期: 2026-08-27
- 功能名: 原生内嵌浏览器 (WebView2) + 实时抓包 + 自动化可视化 + 通过判定修复
- 分支: 非 Git 工作区

## 需求与根因

1. 旧内置浏览器为「无头 Playwright + 截图流」远程画面, 帧率个位数 fps,
   手感死板; 用户要求改为原生内嵌浏览器: 真渲染真事件, 能看到自动化如何
   操作 (验证码点击位置), 并可直接在页面手动输入短信验证码。
2. 实测日志发现误判: 图标验证码第一次已实际通过 (站点已发短信), 但旧判定
   以「弹窗 #eject 仍在 = 未通过」为依据判失败, 触发无谓刷新重试, 浪费
   尝试次数并打乱流程。根因: 通过后弹窗可能切换到短信步骤而仍然存在。
3. 为下一步「除图形验证码模拟点击外, 其余步骤全部改调接口」做准备, 需要
   实时抓包能力 (用户手动走流程, 工具记录全部请求/响应供分析)。

## 涉及文件

- 新增 `core/browser_win.py` (原生浏览器窗口 + JS 桥接 PageShim + 抓包 + 点击标记)
- `core/worker.py` (重写: 去 Playwright/截图流, 接 NativeBrowser, 抓包落盘)
- `core/web_flow.py`、`core/captcha_handler.py` (适配 Shim + 判定修复)
- `api.py`、`main.py`、`ui/index.html`、`ui/app.js`、`ui/style.css`、`build.py`

## 关键设计

- **原生窗口**: `webview.create_window` 支持 start 后从非主线程动态建窗
  (pywebview 6.2.1 验证); WebView2 `ExecuteScriptAsync` 等待 Promise 返回
  解析值。`main.py` 以 `private_mode=False + storage_path=webview_data/`
  持久化 cookie (保留登录态)。用户可直接在窗口点击/输入/滚动。
- **JS 桥接 PageShim**: 提供 web_flow/captcha_handler 所需的 Playwright
  兼容子集 (evaluate/eval_on_selector/query_selector(_all)/click(position)/
  goto/reload/url/bring_to_front/wait_for_selector)。页内注入 `window.__cx`
  (每次 loaded 事件重注入, 幂等): 选择器引擎 (text=/tag:has-text("x")/CSS,
  取最小可见匹配)、元素注册表句柄、fill 用原生 value setter + input 事件、
  坐标点击 dispatch mousedown/mouseup/click MouseEvent 序列。
- **自动化可视化**: 所有自动化点击在页面叠加红圈编号标记 (fixed 定位,
  2.5s 淡出); 验证码三点按 1/2/3 编号。
- **抓包**: 原生 `request_sent/response_received` 事件 (method/url/status,
  全量含静态资源) + 页内 fetch/XHR 钩子 (请求体/响应体, 截断 3000 字符);
  worker 1s 排空: 内存 500 条供 UI「浏览器」页抓包面板展示, 全量追加
  `netlog.jsonl` (2MB 轮转保留尾 800 行), xhr 记录摘要进运行日志。
- **通过判定修复**: `_wait_result` 每轮先查 `_sms_sent` (倒计时/重新获取
  文案) —— 站点仅在验证通过后发短信, 是权威通过信号, 弹窗仍在也判 pass;
  web_flow 增加双兜底: 验证码判失败后 8s 内捕获到短信视为实际通过; 等码
  循环中页面出现「批量续期」(用户浏览器内手动完成登录) 直接跳过短信步骤。
- **指令条获取**: 原生窗口无元素截图, 改 `get_tip_icons` JS 直取
  `.cx_click-tip` 内 3 个目标图标 `<img>` src 下载 2x 放大 (更精确);
  `compose_tip_strip` 拼单条供 VLM 两图模式。
- UI 浏览器页: 去远程画面/键盘转发, 改为窗口状态卡 + 原生窗口说明卡 +
  实时抓包列表 (点击行看请求/响应体详情)。build.py 去掉 collect-all playwright。
