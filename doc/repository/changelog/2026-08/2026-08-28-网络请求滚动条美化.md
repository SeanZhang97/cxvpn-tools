# 网络请求滚动条与交互体验优化

- 日期: 2026-08-28
- 功能名: 内嵌浏览器滚动条及全局流程交互优化
- 分支: 非 Git 工作区

## 需求概述与问题根因

网络请求抽屉使用 WebView2 系统默认滚动条，白色轨道、上下箭头和方形滑块与深色
浮层不协调。该抽屉位于 `OVERLAY_JS` 创建的 Shadow DOM 内，主界面
`ui/style.css` 的全局滚动条样式无法穿透，因此必须在浮层自身定义主题。

完成滚动条调整后继续审查现有页面，发现未配置目标 VPN 时首页仍显示连接动作、
断开按钮未按状态禁用、配置删除没有确认且会遗留目标/凭据引用，以及部分保存失败
会静默关闭弹窗或保留错误的开关状态。轮询还会并发重入并在非日志页持续读取日志。

## 关键设计

- 网络列表改为仅纵向滚动，避免窄窗口出现无意义横向滚动条。
- `.net-table` 与 `.net-detail` 共用 8px 深色圆角滚动条，轨道保持低对比度，
  滑块 hover 时使用浅紫色高亮。
- 显式隐藏 WebKit 滚动条上下按钮并处理滚动条角落；同时保留 Firefox
  `scrollbar-width` / `scrollbar-color` 兼容声明。
- 侧栏导航改为语义化按钮，补充键盘焦点态；开关保留可聚焦输入元素，设置页限制
  内容宽度，表格和弹窗增加窄窗口适配。
- 首页根据目标和连接状态显示“配置 VPN”或“连接 VPN”，仅在已连接时允许断开；
  开关保存失败自动恢复原值。
- VPN 新增、凭据、超星账号和 AI 模型统一增加校验、加载态与行内成功/失败反馈；
  “测试连通性”会先保存当前可见模型配置，避免测试旧配置。
- VPN 删除使用应用内确认弹窗；后端删除成功后同步清理匹配的目标 VPN 与工具凭据，
  防止配置指向已不存在的系统连接。
- 状态轮询增加单次互斥，状态接口并行读取；日志仅在运行日志页刷新，减少桥接调用。

## 影响范围

- 影响总览、VPN 配置、超星账号、AI 模型和浏览器页的交互与状态反馈。
- VPN 删除成功后会清理本工具中同名目标和凭据引用；删除失败时配置保持不变。
- 不改变请求采集、授权续期执行逻辑、真实 VPN 拨号协议或配置数据结构。
