# VPN 双栈默认网关配置

- 日期: 2026-08-29
- 功能名: IPv4/IPv6 默认网关编辑与双栈路由冲突检测
- 分支: 非 Git 工作区

## 需求概述与问题根因

Windows RAS VPN 分别保存 IPv4、IPv6 的远程默认网关开关，但管理器原先既不读取、
也不能修改这些配置；连接状态只查询 IPv4 地址和路由，多个 VPN 的默认路由冲突也只
识别 `0.0.0.0/0`，遗漏 IPv6 `::/0`。

## 关键设计

- 从用户 `rasphone.pbk` 读取 `IpPrioritizeRemote` 与
  `Ipv6PrioritizeRemote`，并在新增、编辑 VPN 时允许分别启用或关闭。
- 电话簿写入保留原 BOM、编码和换行格式，通过同目录临时文件原子替换，避免直接覆盖
  中断造成配置损坏；找不到目标条目或写入失败时返回明确错误。
- 系统连接查询同时采集 IPv4/IPv6 地址与路由，保留原聚合字段并新增分协议字段，兼容
  既有总览和调用方。
- 默认路由与子网重叠分析扩展到 IPv6；IPv4、IPv6 默认路由冲突分别提示，便于定位
  实际受影响的协议栈。
- VPN 配置表展示默认网关摘要，编辑弹框增加两个独立开关；已连接条目的路由标签显示
  实际生效的协议族，并提示修改后需要重新连接。

## 影响范围

- Windows 当前用户级 VPN 的新增、编辑、列表展示和路由状态分析。
- 多 VPN 并行连接后的默认路由与网段重叠提示。
- 不修改现有 VPN 连接状态；真实配置只在用户点击保存时写入。

## 注意事项

- 已连接时修改默认网关只更新后续连接使用的电话簿配置；需断开并重新连接后，系统路由
  才会完全按新设置生成。
- 管理器当前通过 `Get-VpnConnection` 管理当前用户级条目；全局 VPN 电话簿通常需要
  管理员权限，不在本功能写入范围内。
