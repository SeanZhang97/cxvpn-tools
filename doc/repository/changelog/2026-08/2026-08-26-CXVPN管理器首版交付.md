# 2026-08-26 CX VPN 管理器首版交付

- 日期: 2026-08-26
- 分支: 非 Git 工作区
- 功能: CX VPN 管理器（超星 VPN 自动授权/续期/连接便携工具）首版

## 需求概述

日常工作需先经 remote.chaoxing.com/vpn 短信授权（8 小时有效）再连接公司 VPN。
要求工具: 自动完成网页授权与短信验证码填写、自动识别图形验证码、自动连接/续期 VPN；
可视化 GUI；可打包为便携 EXE 文件夹 zip 分发；VPN 凭据与 Windows 单一数据源。

## 涉及文件

- 入口/后端: `main.py`、`api.py`
- 核心: `core/worker.py`、`core/web_flow.py`、`core/captcha_handler.py`、
  `core/sms_receiver.py`、`core/vpn_os.py`、`core/vpn_connect.py`、
  `core/ras_cred.py`、`core/config.py`
- 界面: `ui/index.html`、`ui/style.css`、`ui/app.js`
- 构建/资源: `build.py`、`make_icon.py`、`icon.ico`、`ui/logo.png`

## 关键设计

- GUI: pywebview + 深色 Web UI，页面: 总览/VPN 配置/超星账号/AI 模型/浏览器/帮助说明/运行日志。
- 网页流: Playwright channel=msedge + headless，持久化 profile 于 exe 目录 browser_data/。
- 验证码: VLM（OpenAI 兼容接口，sprite 原图 base64 直发返回点击坐标，失败刷新重试 3 次）
  → 工具内人工点击兜底（GUI 弹窗点 3 下回传坐标）。
- 短信码: 只读轮询 Windows 通知中心 wpndatabase.db 的 YourPhoneMessages handler。
- 凭据单一数据源: RasGetCredentialsW 读取回显（密码明文受 Windows 保护不可读）；
  新密码经连接验证后 rasdial /savecredentials 写回 Windows，工具侧不留副本。
- 内置浏览器页: 无头页面实时截图回显，点击截图即操作页面（命令队列保证 Playwright 单线程安全）。
- 便携: PyInstaller onedir --noconsole；config.json/browser_data 随 exe（sys.frozen 定 BASE）；
  build.py 重打包自动保留 dist 下 config.json。

## 影响范围

新增独立工具项目，不影响任何既有系统。

## 注意事项

- config.json 含用户自填的模型 API Key，分发 zip 前应清空或各自填写。
- dist 约 156MB（含 Playwright 驱动），压缩后约 60-70MB。
- 目标机要求: Win10/11 + Edge + WebView2 + 已配对"手机连接"(Phone Link)。
