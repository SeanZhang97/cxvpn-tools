# Windows 统一域名分流

- 日期：2026-08-30
- 功能名：可配置 Windows 统一域名分流
- 分支：非 Git 工作区

## 需求概述

在 Windows 同时使用公司系统 VPN 和代理网络时，由 CXVPN 管理器统一接管流量，
按可配置域名规则选择物理网络、代理订阅、指定 Windows VPN 或阻止连接。规则只处理
域名，不处理 URL 路径；服务启用后不要求 GUI 一直运行。

## 关键设计

- 复用 Mihomo v1.19.30 作为 TUN 数据面，Python 仅负责规则、预检、服务生命周期和 UI。
- 复用 WinSW v2.12.0 将 Mihomo 托管为自动启动的 Windows 服务；应用或关闭配置时通过
  UAC 完成服务注册、替换和注销，避免 GUI 退出后分流中断。
- 精确域名、域名后缀和通配符规则按界面顺序生成 `DOMAIN`、`DOMAIN-SUFFIX`、
  `DOMAIN-WILDCARD`；末尾使用可配置的 `MATCH` 默认出口。
- 物理直连和每条 Windows VPN 均生成绑定 `interface-name` 的 Mihomo `direct` 出口。
  规则命中未连接的 VPN 时按失败关闭处理，不自动泄漏到其它出口。
- 使用代理出口时直接加载 Clash/Mihomo proxy-provider 订阅，不与另一个 Clash TUN 串联。
- 启用前阻止目标 VPN 仍开启 IPv4/IPv6 远程默认网关的配置，也阻止其它活跃 TUN
  默认路由，避免多套全隧道路由相互争抢。
- 配置先经字段校验和 `mihomo -t` 真实解析，再申请 UAC 变更服务；普通设置保存不能
  绕过此原子应用入口。统一分流默认关闭。
- 服务配置只监听 `127.0.0.1` 控制端，并使用随机 secret；ProgramData 服务目录仅
  SYSTEM 和 Administrators 可写，订阅 URL 不写入运行日志。
- 锁定并记录两个上游二进制的 SHA-256，随包附带第三方声明和完整许可证文本。
- 域名分流页的物理接口、默认出口、规则匹配方式和规则出口全部使用应用内深色下拉；
  顶部选项显示名称与说明，规则行保持紧凑。菜单通过 body portal 定位，靠近窗口底部时
  自动向上展开，并支持选中态、长文本省略、滚动及完整键盘导航。
- 单订阅字段升级为最多 16 个 `proxy_providers`，支持每个订阅独立启停、名称、URL、
  更新周期、包含/排除节点筛选，并兼容迁移首版 `proxy_provider_url` 配置。
- 规则和默认出口既可选择合并后的“全部代理订阅”，也可精确选择某个订阅。Mihomo 为
  各订阅节点添加名称前缀，避免不同来源同名节点冲突。
- 全部订阅和单个订阅均支持 `url-test` 自动测速、`fallback` 顺序故障转移和 `select`
  手动选择。运行中的节点列表、当前节点和最近延迟从本地 Controller 读取，手动切换会
  校验节点属于目标组后再调用 Mihomo API。
- 订阅被停用、删除或 VPN 不存在时，界面保留“当前出口不可用”选项，避免规则无提示地
  回退为物理直连。
- 新版分流功能重组为“概览、分流规则、订阅管理、代理节点”四个页签，长表单不再一次性
  展开。概览改为状态指标和动态配置检查；订阅卡默认折叠，摘要展示策略、更新时间、
  节点可用数和当前节点。
- 新增域名命中测试，可在保存前解释某个域名命中了第几条规则、最终出口及当前可用性，
  不发送目标请求，也不修改系统网络。
- 新增运行中订阅立即更新、代理组整组测速、节点搜索和仅看可用筛选；只有手动选择策略
  允许点击节点。修改过但未保存的订阅会禁用立即更新，避免误更新旧配置。
- 新增未保存状态提示、放弃修改、刷新前二次确认和窗口关闭保护；删除或停用仍被规则引用
  的订阅时明确提示影响，不再静默产生失效引用。
- 第二轮视觉重设计将标题说明、运行状态和刷新按钮合并为紧凑头部，四个功能页签改为带
  二级说明的横向分段导航；修复页签继承全局侧栏 `nav` 纵向布局而占满首屏的问题。
- 概览指标支持直接跳转规则、订阅和节点页；页签增加 ARIA 语义、方向键/Home/End 切换，
  切页自动回到页面顶部。空状态、内容卡片与底部保存栏同步调整对比度和信息密度。
- 每张订阅卡新增“查看节点”按钮，点击后自动打开节点页并选中该订阅对应的代理组；订阅
  尚未保存或服务未运行时，节点页保留订阅名称并说明加载条件，避免用户找不到节点入口。

## 影响范围

- 新增侧栏“域名分流”页面和 `routing` 配置块。
- 打包产物新增约 68 MB 的 Mihomo/WinSW x64 运行时。
- 启用时会新增 `CXVPNRoutingService` 系统服务和 `CXVPN-TUN` 网络接口；关闭时注销服务。
- 目标 Windows VPN 必须关闭双栈远程默认网关；第三方代理软件必须关闭 TUN 模式。

## 注意事项

- 首版运行时为 Windows x64；ARM64 尚未提供对应内置二进制。
- 规则只基于域名。HTTPS 加密内容中的 URL 路径不在路由层可见，也不作为产品能力。
- 内部域名若依赖公司专用 DNS，需在 DNS 服务器字段中填入可达的解析器；不同域名使用
  不同 DNS 的细粒度策略尚未在首版 UI 中开放。
