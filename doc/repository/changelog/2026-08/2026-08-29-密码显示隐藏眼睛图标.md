# 密码显示隐藏眼睛图标

- 日期：2026-08-29
- 功能名：敏感输入显示/隐藏图标统一
- 分支：非 Git 工作区

## 需求概述与问题根因

软件内的密码类输入使用「显示/隐藏」文字按钮，占用宽度较大，且在不同表单中视觉不够简洁。改为统一的眼睛开闭线性 SVG 图标。

## 涉及文件

- `ui/index.html`
- `ui/style.css`
- `ui/app.js`
- `tests/test_ui_polish.js`
- `tests/test_ui_state_sync.js`
- `doc/repository/knowledge/modules/CXVPN管理器.md`

## 关键设计

- 覆盖全部 5 处敏感输入：邮箱授权码、AI API Key、VPN 凭据密码、L2TP 预共享密钥、新增 VPN 登录密码。
- `bindSecretToggles()` 按 `.inp-wrap` 自动关联图标按钮和敏感输入，消除分散的五处点击绑定。
- 输入处于 `password` 时显示睁眼图标；切换为明文时显示闭眼图标，并增加 `.is-revealed` 视觉状态。
- 按钮根据 `data-secret-label` 同步更新 `aria-label`、`aria-pressed` 和 `title`，准确区分授权码、API Key、VPN 密码与预共享密钥。
- VPN 凭据和新增/编辑 VPN 弹框每次打开时，通过 `concealSecret()` 恢复密文和睁眼图标。

## 影响范围

仅影响密码与密钥类输入的显示/隐藏控件，不改变任何保存、连接或授权逻辑。

## 验证情况

- `node --check ui/app.js`：通过。
- `node tests/test_ui_polish.js`：通过。
- `node tests/test_ui_state_sync.js`：通过，覆盖睁眼/闭眼 SVG、`password/text` 切换、弹框复位及可访问属性。
- `uv run --with pyinstaller python build.py`：打包成功；`config.json` 打包前后 SHA-256 与大小一致，`app.js`、`style.css`、`index.html` 的产物哈希与源码一致。
- 新版实际窗口抽查：邮箱授权码、API Key 和新增 VPN 密码均显示睁眼图标；空密码框切换后显示闭眼图标，可访问名称同步为「隐藏 VPN 密码」；关闭弹框且未保存配置。

## 注意事项

眼睛图标仅改变当前输入框的本地可见性，不触发保存或对外传输。
