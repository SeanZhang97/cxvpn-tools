# 全页面视觉与提示交互优化

- 日期: 2026-08-28
- 功能名: 页面、弹框、提示与浏览器浮层统一优化
- 分支: 非 Git 工作区

## 需求概述

重新审查总览、VPN 配置、账号设置、AI 设置、帮助、日志和内置浏览器页面，统一
信息层级与弹框样式；将原“立即续期”改为能够同时表达首次授权和续期的通用入口，
保留执行中断能力；同时提升操作成功、失败和前置条件不足时的提示辨识度。

## 问题根因

- 原界面部分页面仍是简单表单或大段说明，标题、摘要、空状态和主要操作层级不统一。
- “立即续期”不能准确描述未授权 VPN 的首次授权场景。
- 内置浏览器在较窄窗口中保持展开的进度卡，会遮挡远端登录表单。
- 原轻提示只有圆点和边框两种状态，成功、失败与警告的语义区分不足；未选择目标
  VPN 时还错误使用了成功状态。

## 关键设计

- 总览入口统一为“立即处理授权”，根据远端状态自动执行首次授权或续期；任务运行时
  原位切换为中断操作，前后端状态文案统一为“授权处理”。
- VPN 配置页增加连接数量、已连接数量和目标状态摘要；账号与 AI 设置页采用统一的
  设置卡片标题；帮助页改为四步快速开始与五组原生折叠说明；日志页增加实时状态、
  记录计数、空状态和复制入口。
- 凭据、验证码、短信、VPN 编辑和危险确认弹框统一尺寸、标题、说明、操作区与关闭
  方式；危险确认默认聚焦取消按钮，降低误操作风险。
- 成功、失败、警告和信息提示使用独立色彩、状态图标、标题、正文和消失进度；提示
  通过 `status` / `alert` 向辅助技术播报。
- 原生浏览器宽度不超过 1100px 时自动收起进度卡，用户手动展开/收起后尊重其选择；
  窄窗口打开网络请求抽屉时同步收起进度卡。

## 影响范围

- 影响所有主界面的视觉层级、帮助与日志交互、应用内弹框、轻提示和浏览器浮层。
- 不改变配置结构、VPN 数据结构、后端授权接口参数或远端站点请求协议。
- `build_tmp` 下文件仅用于本地视觉验证，不进入分发产物。

## 注意事项

- 授权处理中断为协作式中断；当前单次页面脚本或模型请求返回后，在下一个检查点停止。
- 提示框不会阻断当前操作，成功提示停留时间短于失败提示；错误详情仅展示首行，完整
  异常仍由现有日志体系记录。
