# 验证码网络异常人工降级

- 日期：2026-08-29
- 分支：非 Git 工作区
- 功能：验证码资源直连重试与 AI 故障人工降级

## 需求概述与问题根因

点击获取验证码后，系统可能在图标验证码弹窗刚出现时抛出
`WinError 10061`，随后整次授权被 Worker 判为失败并进入 10 分钟重试。

根因是验证码图片下载和视觉模型请求直接使用系统代理环境：VPN 或代理工具退出后，
Windows 可能仍保留指向不可用本地端口的代理设置。验证码图片下载异常会直接向上抛出；
视觉模型的 HTTP 或连接异常也没有统一标记为可人工接管的故障，导致已有人工点选能力无法及时兜底。

## 涉及文件

- `core/captcha_handler.py`
- `tests/test_captcha_manual_fallback.py`
- `doc/repository/knowledge/modules/CXVPN管理器.md`

## 关键设计

- 验证码图片先按系统网络设置下载；遇到连接拒绝、超时或系统网络错误时，禁用系统代理并直连重试一次。
- 将视觉模型的 HTTP 错误、连接失败、超时和底层网络错误统一转换为 `VlmUnavailableError`。
- `handle_captcha()` 捕获该故障后立即停止本轮自动识别并进入现有人工点选流程，不再消耗剩余自动识别次数，也不再让异常冒泡至 Worker。
- 日志只记录请求端点与错误摘要，不记录 API Key 等敏感配置。

## 影响范围

- 仅影响图标验证码的资源获取、视觉模型异常处理和人工兜底路径。
- 短信后台捕获、授权成功判断、VPN 连接与定时续期策略未改变。
