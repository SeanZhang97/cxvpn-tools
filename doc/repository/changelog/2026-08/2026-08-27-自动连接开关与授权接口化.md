# 自动连接开关与授权/下线接口化

- 日期: 2026-08-27（第三版）
- 功能名: auto_connect 开关 (默认关) + 授权接口 batchLoginVpn 接入
- 分支: 非 Git 工作区

## 需求与根因

1. 用户: 本工具是 VPN 管理器, 可能有多个 VPN, 只要手动连接 ——
   打开工具不应自动拨号/重连, 需开关控制。
2. 用户补抓了批量下线/批量授权操作, 授权接口可接口化, 去掉 DOM 兜底依赖。

## 涉及文件

- `core/worker.py` (auto_connect 门控自动拨号/重连)
- `api.py` (手动连接 691 → 触发续期自愈)
- `core/web_flow.py` (授权接口 batchLoginVpn; 行状态 need_auth 判定)
- `ui/index.html`、`ui/app.js` (总览「自动连接」开关卡 + 帮助)

## 关键设计

- **auto_connect 开关 (默认关)**: worker 30s 重连循环仍更新连接状态供 UI
  展示, 但自动拨号/重连仅当 `cfg.auto_connect=true`; 连接一律由「总览」
  手动「连接 VPN」发起。自动续期 (auto_renew) 独立不受影响。
- 手动连接报 691 → `renew_requested.set()` (授权到期自愈, 自动连接关闭
  时也生效)。
- **接口清单补全** (抓包 + 站点 vpnLogin.js 核实):
  - 授权 `POST /vpn/batchLoginVpn` (phoneNumber&vpnIdsSel); 单行
    `/vpn/loginVpn` (reLogin: ''=授权 '2'=续期 '1'=IP切换)
  - 下线 `POST /vpn/closeUser/user` (vpnIds&phoneNumber, 响应 data.success)
  - IP 切换 `POST /vpn/batchReLoginVpn/changeIp`
- web_flow 目标行动作判定: need_auth = DOM 行文本含「未授权/激活」(已登录
  态) 或 checkCode 数据无 exptime / vpnUserActivate!=1 (登录态) →
  batchLoginVpn; 否则 addTime。失败仍回退页面点击。

## 影响范围与验证

- py_compile/node --check 过; 已重打包。
- 待实测: 未授权态自动续期走 batchLoginVpn; 自动连接关闭时启动不拨号。
- 内嵌面板补充: 非 /vpn 页 (授权成功页等) 左上角注入浮动「返回 VPN
  操作页」按钮 (INSTALL_JS backbar)。核实站点行为: 批量下线**不开新页**
  (弹框内 toast+行变未授权, 弹框按设计保留); 开新页的仅授权/续期/IP切换
  成功页, 面板同窗口接管显示。
- **开局假死修复**: UI 轮询 vpn_status 不再现跑 rasdial/PowerShell, 改读
  worker 缓存 (worker 启动 5s 后首查、每 30s 实查; 手动连接/断开即时更新
  缓存) —— 冷启动阶段进程创建+杀软扫描与 GUI 主线程争抢资源是假死主因。
  main.py 增加 startup.log 启动耗时日志 (imports/shown/loaded), 再假死可
