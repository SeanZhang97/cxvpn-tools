# 2026-08-27 授权续期全量批处理

- 日期: 2026-08-27
- 功能名: VPN 授权/续期全量批处理 (不再依赖配置的目标 VPN)
- 分支: 非 Git 工作区

## 需求概述

原流程按工具配置的 vpn_name 在页面匹配唯一目标行后仅授权/续期该行;
改为**授权页面中有哪些行就批量处理哪些行**, 与工具配置无关
(配置目标仅用于"连接"语义, 不变)。

## 涉及文件

- `core/web_flow.py` (批处理主流程 + 逐行页面兜底)
- 知识库 modules/CXVPN管理器.md、common/超星图标点选验证码识别.md

## 关键设计

- 页面行按状态分两组: 未授权/未激活行 → `POST /vpn/batchLoginVpn`
  批量授权; 其余行 → `POST /vpn/batchReLoginVpn/addTime` 批量续期;
  参数 `vpnIdsSel` 为**逗号拼接多 id** (与站点 vpnLogin.js
  `batchInput.join(",")` 同款), phoneNumber 照旧。两组接口均成功即
  完成, 任一失败进入页面兜底。
- 页面兜底改为逐行点击: 每次 evaluate 找第一行未处理且有可用按钮
  (授权/激活 或 续期) 的行点击, 行 id (input[batchVpnId]) 去重,
  防授权后页面重渲染导致重复点击; 每行最多处理一次, 上限 90s/30 行;
  兜底零点击视为失败 (返回 False 触发重试)。
- need_auth 判定收敛为 `/未授权|未激活/` (去掉裸"激活"匹配, 避免
  已激活行被误当待授权)。
- 移除 `_norm` 目标名匹配与未使用 import。

## 影响范围

- ensure_authorized 授权/续期语义 (接口路径参数变为多 id); 目标 VPN
  匹配逻辑删除, `vpn_name` 仍只影响连接目标。日志新增 `[web] 页面 N 行
  (授权 x / 续期 y)` 与批量结果明细。

## 验证情况

  重新打包 (BUILD_EXIT=0), config.json 打包前后保持。
- 未执行: 真实站点联调 (需授权); 多行组合 (授权+续期混合) 场景
  需在线观察站点返回。

## 注意事项

- 批量接口对"已授权行"重复授权会被服务端拒绝/忽略时, 日志会显示
  返回内容, 分组依据为页面实时状态; 兜底点击同样按行实时状态选按钮。
- 页面行数为 0 时流程按失败返回, worker 10 分钟后重试。
