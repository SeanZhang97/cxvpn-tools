# 总览 VPN 编辑弹框交互

- 日期：2026-08-29
- 功能名：总览 VPN 新增与编辑就地交互
- 分支：非 Git 工作区

## 需求概述

总览页的「添加 VPN 配置」和每条 VPN 右侧编辑入口不再跳转到「VPN 配置」页，改为直接打开现有的新增或编辑弹框。

## 问题根因

总览连接行的省略号按钮和空槽位按钮仍绑定 `goToPage('vpns')`，没有复用配置页已经完整的 `openModal()` 表单交互。

## 涉及文件

- `ui/app.js`
- `tests/test_ui_polish.js`
- `doc/repository/knowledge/modules/CXVPN管理器.md`

## 关键设计

- 空槽位直接调用 `openModal(null)` 打开新增 VPN 弹框。
- 总览连接行将完整 `profile` 传入行渲染，右侧省略号直接调用 `openModal(profile)` 打开对应 VPN 编辑弹框。
- 保留现有 `syncVpnUi({ forceRefresh: true, refreshConfig: true })` 保存链路：保存后强制重读 Windows VPN 快照，只更新 VPN 配置表、总览连接区和相关统计，不切换页面。
- 按钮的 `title` 与 `aria-label` 从「管理」改为「编辑」，与实际行为一致。

## 影响范围

仅影响总览页 VPN 新增与编辑入口；「VPN 配置」页的新增、编辑和刷新行为保持不变。

## 验证情况

- `node --check ui/app.js`
- `node tests/test_ui_polish.js`
- `node tests/test_ui_state_sync.js`
- `uv run --with pyinstaller python build.py`：打包成功，产物 UI 资源与源码一致，`config.json` 打包前后未变。
- 打包产物实际界面检查：总览空槽位打开「新增 VPN」弹框，已连接 VPN 的省略号打开该条目「编辑 VPN」弹框，关闭后均保持在总览页；未执行保存。

## 注意事项

弹框保存依然会调用 Windows VPN 配置能力；本次离线回归不访问真实外部服务，也不创建或修改系统 VPN。
