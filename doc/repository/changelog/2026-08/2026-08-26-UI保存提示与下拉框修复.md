# UI 保存提示与下拉框修复

- 日期: 2026-08-26
- 功能名: 超星账号保存反馈 / VPN 编辑弹框下拉
- 分支: 非 Git 工作区

## 需求与根因

1. 「超星账号」页点保存后无任何成功/失败提示。
2. VPN 编辑弹框一打开类型下拉就处于展开状态，且无法收起。

根因: `ui/style.css` 只有 `.modal.hidden { display:none }`，不存在通用
`.hidden` 规则；`#m-type-list` 上的 `hidden` 类对 `.dd-list` 无任何样式
效果，故列表常显、JS 切换类名也无效。

## 涉及文件

- `ui/app.js`
- `ui/style.css`

## 关键设计

- 保存按钮复用现有 `toast()` 组件: 成功/失败/手机号为空三种提示；
  保存期间禁用按钮防重复提交；顺带同步总览页续期间隔显示。
- 新增通用规则 `.hidden { display: none !important; }`，替代原
  `.modal.hidden`（职责已被覆盖）。
- `openModal()` 每次打开弹框时对 `#m-type-list` 强制 `add('hidden')`，
  双保险。

## 影响范围与验证

- 仅前端，不涉及后端接口。
- 已随当日打包交付，下拉默认收起、点按钮/选项/外部均能收起。

## 注意事项

- 打包版加载 `dist/.../_internal/ui/` 下内嵌 UI；仅改 UI 文件时可
  Copy-Item 覆盖 dist 对应文件免重打包，改 Python 后端则必须重打包。
