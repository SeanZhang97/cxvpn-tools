# 浏览器自动化入口与帮助标签对齐

- 日期：2026-08-29
- 功能名：浏览器快捷执行自动化与帮助页标签排版
- 分支：非 Git 工作区

## 需求概述与问题根因

浏览器页只能打开或刷新内置浏览器，执行授权自动化仍需返回总览；帮助说明折叠项使用弹性均分布局，标签位置会随左侧标题宽度变化，纵向观察时不在同一轴线上。

## 涉及文件

- `ui/index.html`
- `ui/style.css`
- `ui/app.js`
- `tests/test_ui_polish.js`
- `tests/test_ui_state_sync.js`
- `doc/repository/knowledge/modules/CXVPN管理器.md`

## 关键设计

- 浏览器命令栏新增「执行自动化」按钮，直接复用现有 `renew_now` / `cancel_renew` 授权流程，不新增后端接口。
- 总览与浏览器按钮共用 `handleRenewalAction()` 和 `renderRenewalActionButtons()`，同步启动、中断、禁用、颜色及可访问名称。
- 浏览器未启动时点击「执行自动化」仍由 Worker 按原流程创建浏览器并开始任务；任务执行中按钮切换为「中断自动化」。
- 帮助折叠项标题改为固定三列网格，状态标签统一居中到 88px 列，展开符号固定在最右侧。

## 影响范围

仅调整浏览器页授权自动化入口和帮助说明的视觉布局，不改变授权流程、浏览器生命周期或配置数据。

## 验证情况

- `node --check ui/app.js`：通过。
- `node tests/test_ui_polish.js`：通过。
- `node tests/test_ui_state_sync.js`：通过，覆盖总览和浏览器按钮的空闲、运行及中断状态同步。
- `uv run --with pyinstaller python build.py`：打包成功；`config.json` 打包前后 SHA-256 与大小一致，`app.js`、`style.css`、`index.html` 的产物哈希与源码一致。
- 新版实际窗口抽查：浏览器命令栏按钮间距正常且地址未被挤压；帮助页五个类型标签纵向对齐。仅导航和折叠帮助项，未点击自动化按钮、未发起授权任务。

## 注意事项

浏览器页按钮执行的是与总览「立即处理授权」完全相同的全量授权/续期任务，不是单纯刷新当前网页。
