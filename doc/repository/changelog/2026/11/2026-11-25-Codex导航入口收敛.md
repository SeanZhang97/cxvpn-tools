# Codex 导航入口收敛

- 日期：2026-11-25
- 分支：fix/auto-renew-slider-captcha
- 功能：隐藏侧栏 Codex 菜单，保留页面、公开 API 与后台配置联动

## 需求概述

用户不再需要在侧栏显示 Codex 入口，但明确保留后台功能。本次只收敛导航可见性，不删除或停用 Codex 能力。

## 涉及文件

- `ui/index.html`：侧栏 `data-page="codex"` 按钮增加既有 `.hidden`；`page-codex` 与配置弹窗保留。
- `tests/test_ui_codex_transport.js`：增加“导航隐藏 + 页面保留”静态契约。
- `tests/test_proxycore.py`：启动夹具补充既有 `_start_web_quick` mock，使测试能执行到 Codex 断言。
- `doc/repository/knowledge/modules/Codex代理配置同步.md`：同步当前入口与后台边界。

## 关键设计

- 复用全局 `.hidden { display: none !important; }`，不新增另一套隐藏样式，也不改变通用导航绑定。
- `bindCodexPage()`、Codex 公开 API、`core/codex_*`、启动流程均不修改；直接 `goToPage('codex')` 仍能激活保留页面。
- `Api._close_codex_after_proxy_disabled()` 在软件代理由启用成功切换为关闭后的清理联动原样保留；启动复核不写 Codex 的行为不变。

## 影响范围

- 侧栏不再显示 Codex 菜单，页面 DOM、控件和 API 仍存在。
- 原有“请到 Codex 页面重试”等后台文案未改；普通用户当前没有可见侧栏入口，这是本次有意的入口收敛，不是功能删除。

- `tests/test_ui_codex_transport.js`、`tests/test_ui_polish.js` 通过，确认菜单隐藏且页面、控件与 ID 绑定完整。
- `tests.test_api_codex_proxy`、`tests.test_proxycore` 共 29 项通过，覆盖公开 API、启动不写 Codex、成功关闭软件代理后的清理及失败不清理。

  实机网页快开与总览侧栏均不再显示 Codex，页面 DOM 与后台代码未删除。
