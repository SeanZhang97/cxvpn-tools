# 主窗口状态恢复

- 日期：2026-11-26
- 分支：fix/auto-renew-slider-captcha
- 功能：软件重启后恢复主窗口尺寸、所在显示器位置和最大化状态

## 需求概述

此前打包或优雅重启会按固定的 1440×900 创建主窗口，用户移动、调整尺寸或最大化后，下次启动无法沿用。
需要保存并恢复主窗口状态；显示器移除或坐标越界时不能将窗口恢复到不可见区域。Edge 窗口与标签页仍由
Edge 自身会话机制管理，本需求只处理 CX Toolkit 主窗口。

## 涉及文件

- `main.py`：向 `DesktopController` 提供主配置中的窗口状态读写回调。
- `api.py`：新增 `_save_window_placement`，在退出边界复用现有主配置事务保存。
- `core/config.py`：新增可选 `window_placement` 配置项，默认空对象，不改变 SQLite schema。
- `core/windows_desktop.py`：窗口状态捕获、恢复、可见区域回退、最小化状态跟踪和保存去重。
- `tests/test_windows_desktop.py`（本地验证，不纳入提交）：多显示器、越界、尺寸钳制、去重与失败路径。
- `doc/repository/knowledge/modules/CXVPNTools.md`、`doc/repository/knowledge/INDEX.md`、本记录及月份索引。

## 关键设计

- 普通窗口保存 `Bounds`；最大化与最小化保存普通 `RestoreBounds` 和最后非最小化显示状态。
- `DesktopController.start` 在首屏显示前恢复尺寸、位置和 `FormWindowState`，不改变现有 hidden/start UI ready 流程。
- 优雅退出、打包重启、关机及任务管理器关闭前保存；`complete_exit` 补采最终位置，等值配置不重复写入。
- 拖动与缩放过程不写配置，隐藏到托盘不视为退出；保存失败仅记录日志，不阻断退出。
- 原窗口仍至少露出 160×48 且标题栏可见时保留原位置；否则在最近显示器工作区居中，尺寸按
  `min(max(原尺寸, 1080×680), 工作区尺寸)` 约束，避免显示器拔出后窗口丢失。
- 复用主配置 `window_placement` 与 SQLite 事务，不新增数据库表、不引入第二份活动配置，也不改变
  续期内嵌浏览器已有的位置保持逻辑。

## 影响范围

- 仅 CX Toolkit 主窗口的启动布局与退出持久化；页面、未保存输入、托盘、Edge 和后台任务行为不变。
- `window_placement` 为无害的本地 UI 状态，可随兼容 JSON 导出；不包含凭据或业务数据，SQLite schema 保持 7。
- 旧配置没有该字段时仍使用固定默认窗口，首次优雅退出后开始保留。
