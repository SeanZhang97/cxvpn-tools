# 滑块取图网络回退

- 日期：2026-11-25
- 功能：自动授权/续期的滑块验证码取图可靠性
- 分支：fix/auto-renew-slider-captcha

## 需求概述与根因

15:00 和 15:16 的自动续期均启动滑块验证，但 Python 后台下载背景图连续 10 次
`URLError`，未进入图像匹配和拖动，随后转人工并在等待超时后重试。相同时刻
WebView2 对同一验证码 CDN 的背景图和拼图请求均返回 HTTP 200。

根因是滑块识别使用独立 `urllib` 下载图片，与 Chromium 的 DNS、代理、TCP/TLS
路径不同，且没有点选验证码已有的无代理直连回退。原日志只记录异常类型并丢弃
`URLError.reason`，无法继续区分底层网络原因。

## 关键设计

- `PageShim`/`NativeBrowser` 新增 `read_image_bytes()`，通过 CDP
  `Page.getFrameTree` 和 `Page.getResourceContent` 读取当前页面已加载的 Base64 图片。
- 滑块优先复用 WebView2 图片；读取失败后回退 Python 默认下载，网络异常再使用
  `ProxyHandler({})` 直连一次，不改变图像匹配、原生拖动和站点结果判定。
- 每张图的浏览器读取和两级 Python 下载共享 10 秒期限，浏览器读取最多占 2 秒；
  保留 HTTPS 主机/路径白名单和 1 MiB 大小限制。
- 网络日志记录来源、阶段、耗时、异常类型和脱敏后的底层原因，挑战 URL 与查询参数
  不写入新增错误日志。
