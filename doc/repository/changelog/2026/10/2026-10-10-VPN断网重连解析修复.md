# VPN 断网重连解析修复

- 日期：2026-10-10
- 分支：main（保留既有工作区改动）

## 问题根因

拔插网线后孙河 IKEv2 连接断开，重新拨号持续返回 628；RasClient 与 IKE
记录显示服务器域名被解析为 TUN fake-IP。重启 RasMan/IKE 服务不会修改
DNS 分流配置。原先生成配置未排除 VPN 服务器域名，预解析还可能把
fake-IP 当成真实地址写入 TUN 排除路由。

## 关键设计与影响范围

- 所有 Windows VPN 的服务器域名自动加入运行配置 fake-IP 排除项，使用
  当前有效 direct DNS；精确物理出口规则优先于业务规则、全局 MATCH。
- 系统预解析返回虚拟地址或失败时，以当前核心真实 DNS API 查询 A/AAAA。
  总期限 5 秒，每请求 2 秒；某地址族失败不丢弃另一族成功结果。
- 未取得真实地址时给出警告，绝不把 fake-IP 加入 TUN 排除路由。
- 保护仅影响生成配置，不改写 DNS 草稿、VPN 服务器、账号密码或用户业务规则。
  覆盖已连接、未连接、未被业务规则引用的 VPN，以及系统代理快切待机配置。
- 沿用既有原生服务应用、运行验证和回滚事务，无新增依赖或 UI 文案。
