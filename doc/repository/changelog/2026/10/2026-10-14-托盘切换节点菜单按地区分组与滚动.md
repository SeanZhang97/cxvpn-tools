# 托盘切换节点菜单按地区分组与滚动

- 日期：2026-10-14
- 分支：main
- 现象：托盘右键「切换节点」二级菜单按订阅平铺全部节点，节点多时一次铺开过高、撑满屏幕；超过 24 个的节点被静默截断不可见，没有滚动手段，也看不到节点的延迟或可用状态。
- 根因：`Api.desktop_quick_snapshot` 为避免菜单过高把每订阅节点截断到 24 个；`DesktopController._on_menu_opening` 重建菜单时未设置 `ToolStripMenuItem.MaxDropDownItems`（WinForms 默认对下拉项数无上限、不渲染滚动箭头）；快照也只带节点名和选中态，不带延迟/可用数据；订阅信息伪节点（剩余流量、套餐到期等）混在可选节点里占位。
- 涉及文件：`core/routing_auto_policy.py`、`core/windows_desktop.py`、`api.py`、`tests/test_routing_auto_policy.py`、`tests/test_api_desktop_actions.py`、`tests/test_windows_desktop.py`。
- 设计：
  - **地区识别移植到 Python**：`routing_auto_policy.node_region_code(name)` 镜像应用内节点菜单（`ui/routing_nodes.js`）的识别规则——国旗 emoji 优先，其次按别名长度降序的提示词（长名称先匹配，避免短别名抢先命中），再是带词边界的大小写敏感两/三字码（如 `HK-01` 命中 HK、`STATUS`/`hk-01` 不命中），兜底 `OTHER`；别名匹配前做 NFKD 分解并去组合附加符。`REGION_PRIORITY` 与 JS 端保持一致。结果用 `lru_cache` 缓存，托盘重复打开不重复扫描。
  - **快照分组**：`desktop_quick_snapshot` 先剔除订阅信息伪节点（`_TRAY_METADATA_NODE_RE`，规则与 `ui/routing.js` 的 `isMetadataNode` 同步），排序（选中置顶→存活→延迟→名称）并按 `TRAY_SNAPSHOT_NODE_LIMIT`（200）截断后，输出 `groups: [{code, label, nodes}]`；地区顺序与应用内地区筛选一致（数量降序→REGION_PRIORITY→代码）；节点携带 `alive`/`delay` 供展示状态。
  - **托盘渲染**：`_on_menu_opening` 对「切换节点」一级、订阅二级、地区三级下拉统一设置 `TRAY_MAX_DROPDOWN_ITEMS`（12），超出渲染 WinForms 原生上下滚动箭头；订阅内只有单一地区时保持平铺不加一层；地区子菜单文本带数量（如「香港 (21)」）；节点文本追加状态后缀——已测速显示「· 66ms」，`alive=False` 显示「· 不可用」，未测速不加后缀。`item.Tag` 仍为 `provider_id\0节点名`，`desktop_select_node` 按完整持久化快照校验，选择逻辑不变。
  - UI 深色滚动条规范（ui/style.css）针对 WebView 界面，原生托盘菜单使用 WinForms 自带滚动箭头，不适用该规范。
- 验证：`tests.test_routing_auto_policy` 新增节点名地区识别测试（中文、英文带空格、国旗 emoji 非 BMP、词边界与大小写不命中共 13 例）；`tests.test_api_desktop_actions` 6 通过（新增：地区分组顺序与数量、订阅信息伪节点剔除、250 节点按 200 截断）；`tests.test_windows_desktop` 25 通过（新增：地区子菜单文本/数量/状态后缀/Tag/Checked 与三级 `MaxDropDownItems`、单一地区保持平铺且 30 项可滚）。`tests.run_business_offline` 223、`tests.run_proxy_lifecycle_offline` 221、`tests.run_routing_offline` 349 通过 1 预期跳过、`tests.test_build_branding` 7、`tests/test_ui_polish.js` 全部通过。
- 打包：`uv run --with pyinstaller python build.py` 重新打包并自动启动新版；需在新版托盘实测：节点多的订阅按地区分组、每组超过 12 个出现滚动箭头、节点名后显示延迟或「不可用」、剩余流量/套餐到期等条目不再出现在菜单里。
