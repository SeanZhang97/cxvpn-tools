- 日期：2026-10-19
- 分支：`codex/pr-1-compatibility`，合入 `feat/local-subscription-and-routing-fixes` 后通过 PR #1 合并 `main`
- 来源：https://github.com/SeanZhang97/cxvpn-tools/pull/1

## 需求与根因

接入 PPP/WAN 出口兜底、无代理配置下的选点与提示修正、无 URL 的本地 YAML 订阅。
原 PR 基于旧主分支，与现有模式控制台及业务独立出口探测冲突；原前端判断还遗漏业务出口。

## 关键设计与影响

- 保留当前主分支模式控制台、独立业务出口探测与告警返回，复用已有 `usesProxy`；提示按实际选择的流量模式计算。
- 不把未使用代理订阅等同于全部物理直连，不把探测失败直接断言为物理网络中断。
- PPP 默认路由在 `Get-NetAdapter` 不可见时使用 IPv4 Connected 接口兜底，保留原硬件状态与虚拟接口排除条件。
- 无 URL 订阅生成 `file` provider，先导入缓存再应用；预览不触发系统代理回退，自动更新跳过本地订阅。
- 交付复核补齐前端本地订阅就绪统计，已有缓存不再因 URL 为空显示不可启动；导入入口和更新说明与后端保持一致。
- 区分导入、缓存载入和测速结果；保持 SQLite、缓存指纹、旧 HTTP 订阅与已有 UI 组件契约。
- 不调整数据库 schema、版本号、依赖或网络接管默认值，不发布 Release。
