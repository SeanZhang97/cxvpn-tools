# 最小化恢复空白修复

- 日期：2026-10-15
- 分支：main
- 功能：Windows 主窗口恢复

## 问题与证据

真实窗口最小化后，通过外部窗口激活恢复，可复现主内容持续空白。
页面仍已加载且后台状态正常；诊断表明最小化将 Dock.Fill WebView 缩为 0×0，
恢复后 WinForms 控件尺寸和 Visible 已正常，但 WebView 合成画面未恢复。
关闭到托盘再打开未复现此现象，与总览 CSS 布局无关。

## 涉及文件与设计

- `core/windows_desktop.py`：记录最小化转为正常/最大化状态；通过 BeginInvoke
  延后到 WinForms 布局完成，再同步主 WebView 可见性并请求重绘。
- `tests/test_windows_desktop.py`：覆盖普通缩放不触发、最小化恢复仅排队一次、
  不重载页面、隐藏/销毁/退出取消、显示和排队失败日志。
- `doc/repository/knowledge/modules/CXVPNTools.md`：维护桌面恢复边界。

不刷新页面、不删除缓存、不调整网络配置，保留当前页面、表单草稿及状态订阅。
不修改第三方 pywebview 或系统 WebView2 安装，不新增依赖。

## 验证

- 修复前真实软件及源码窗口均复现空白；修复后源码窗口同路径恢复正常。
- `python -m unittest tests.test_windows_desktop -q`：35 项通过。
- 普通打包成功，13:40:53 产物启动后，真实 exe 的最小化恢复和最大化显示正常。
- 13:47:41 最终产物再次通过最小化恢复复核，节点页搜索文本和 5 项筛选结果保留。
- 真实桌面用户库与兼容 JSON 构建前后摘要核对通过，revision=432；未清空 WebView 缓存。

## 边界

验证仅覆盖当前 Windows/WebView2 环境，不代表所有显卡驱动、DPI 和运行时组合。
