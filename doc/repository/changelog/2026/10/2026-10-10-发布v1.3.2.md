# 发布 v1.3.2

- 日期：2026-10-10
- 功能：提交当前改动、推送 main 并发布 GitHub Release
- 分支：main

## 需求与涉及文件

- `core/version.py`：版本从 1.3.1 更新为 1.3.2，Windows 文件版本同步更新。
- 本次提交包含当前工作区的 2FA Google 导入、卡片与拖拽排序、节点国家地区识别、节点定位边框、实时速率悬停、无效代理修复与 VPN 重连域名保护。
- 具体业务文件、设计与影响见本月对应变更记录；同时提交既有测试、资源、许可证、`design-qa.md` 和知识库改动。
- 发布入口：`build_release.py`、`build_protected.py`、`installer/build_installer.ps1`。

## 关键设计与影响范围

- 版本常量为唯一版本来源，帮助页、更新检查、EXE、安装器和分发文件使用同一版本。
- 默认受保护构建以 Nuitka 编译业务模块，再用 PyInstaller 收集；保留业务源码及字节码排除断言。
- 分发安装器、程序 ZIP、两个 SHA-256 文件及 manifest，不包含真实用户配置、主库或凭据。
- 构建及重启通过桌面数据视图核对 SQLite 和兼容 JSON；2FA schema v5、密文及账号顺序保持兼容。

- 40 项 2FA、Google 迁移与排序离线测试通过。
- 108 项分流、地区规则、VPN 服务器解析、无效代理与 PowerShell 输出测试通过。
- 29 项状态恢复与发行构建离线测试通过。
- 11 个前端检查脚本通过，覆盖 2FA 导入和排序、节点、地区浮层、选择状态、速率悬停、自定义下拉框与全局滚动条。
- 使用临时用户库及模拟外部调用验证，未执行真实平台登录、网络拔插或完整安装升级回归。
- 受保护构建、分发核对及远端发布结果在交付阶段补充。
