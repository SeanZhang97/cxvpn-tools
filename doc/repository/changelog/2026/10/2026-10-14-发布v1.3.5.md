# 发布 v1.3.5

- 日期：2026-10-14
- 功能：提交 VPN 出口规则陈旧修复、推送 main 并发布 GitHub Release
- 分支：main

## 发布内容

- 修复待机核心基线失真：VPN 断开期间生成的待机配置不再在快切激活后长期以陈旧物理出口承载 `vpn:` 规则域名（本次现象为 chaoxing.com 有序规则仍从物理出口 IP 发出）。
- 快切开启前复核目标 VPN 连接状态与基线，不一致自动降级为完整应用重新生成出口规则。
- VPN 状态联动 worker 与启动对账新增服务兼容性诊断：服务与内置运行时不一致时限频留痕提示，不再静默停摆。
- 包含自 v1.3.4 以来的总览 VPN 编辑回显修复与 VPN 列表拖拽排序持久化、行高统一（f78825b）。

## 需求与涉及文件

- `core/version.py`、`build_version.txt`：版本从 1.3.4 更新为 1.3.5。
- `core/routing.py`：待机核心安装成功后记录 `_runtime_vpns` 基线；`apply()` 快切开启前复核目标 VPN 状态。
- `core/routing_vpn.py`、`api.py`：服务不兼容停摆态的可观测性与限频提示。
- 具体根因、设计与实测验证见 [待机基线失真导致VPN出口规则陈旧](2026-10-14-待机基线失真导致VPN出口规则陈旧.md)。
- 发布入口：`build_release.py`、`build_protected.py`、`installer/build_installer.ps1`。

## 注意事项

- 升级后首次完整应用分流时，后台路由服务会请求一次系统授权（UAC）完成自更新，属正常流程。
- 分流配置 schema 未变更，升级后无需重新配置。
- 本机新版启动与产物检查不代表全新电脑安装或所有网络环境验证通过。
