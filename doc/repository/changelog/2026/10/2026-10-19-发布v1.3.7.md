# 发布 v1.3.7

- 日期：2026-10-19
- 功能：合并 PR #1 后发布兼容修复与已保留的本地界面修改
- 分支：main

## 发布内容与涉及文件

- `core/routing*.py`、`ui/proxy.js`、`ui/routing.js`：本地文件订阅就绪状态与手动选点兼容，PPP 网卡识别回退，保留业务域名独立出口。详见同日 PR1 修复记录。
- `core/windows_desktop.py`：最小化恢复后在 UI 线程重新布局、重绘 WebView，不重新加载页面；退出、隐藏和销毁状态跳过恢复。
- `ui/proxy.js`：区分代理核心运行状态和遥测连接状态，避免等待遥测时误报代理关闭。
- `ui/routing.js`、`ui/style.css`：聚合出口展示、绕过计数修复、节点布局、全屏响应式和默认 VPN 操作按钮一致性；沿用已有文案与组件。
- `tests/test_windows_desktop.py`、相关 UI 测试：覆盖恢复异常、状态判断与响应式布局。
- `core/version.py`、`build_version.txt`：版本更新为 1.3.7。
- 保留并提交此前本地修改及其五份开发记录、对应知识文档，不包含用户数据和构建缓存。
