# 发布 v1.3.6

- 日期：2026-10-15
- 功能：提交首页代理总览重设计与路由快切扩展、推送 main 并发布 GitHub Release
- 分支：main

## 发布内容

- 首页代理总览重设计：新增「接管与策略」面板，接管方式（系统代理 / TUN）与流量策略（规则 / 全局）改为磁贴选择；TUN 冲突扫描常开采集，未启用 TUN 时也能在入口提前展示冲突预检提示。
- 默认出口快速切换：总览新增默认出口选择浮层，一键切换物理网络 / 代理 / VPN / 拦截，选择后立即应用，无需进入高级分流。
- 订阅概览新增节点质量分布与优选节点视图，实时速率曲线改由 uPlot 渲染，悬停数值连续。
- 后端快切接口 `set_routing_enabled` 支持接管方式参数；新增 `set_routing_default_outbound` 只改默认出口，避免前端旧快照覆盖完整配置。
- 分流应用日志补充 capture 维度与请求已提交 / 后台已领取 / 执行结果记录。
- 包含自 v1.3.5 以来的托盘切换节点菜单按地区分组滚动与残影图标系列修复（f01ffa0）。
- 更新 AGENTS.md 打包优雅关闭约定：由 `build.py` 统一发送 Shutdown 事件收敛运行实例，不再手动强制关闭。

## 需求与涉及文件

- `core/version.py`、`build_version.txt`：版本从 1.3.5 更新为 1.3.6。
- `api.py`：`set_routing_enabled` 增加 capture_mode 参数；新增 `set_routing_default_outbound`。
- `core/routing.py`：路由 setup 常开 TUN 冲突扫描；分流应用日志补 capture 维度。
- `ui/index.html`、`ui/proxy.js`、`ui/style.css`、`ui/routing.js`、`ui/vendor/uPlot.*`：首页总览重设计与速率曲线渲染库。
- 测试：`tests/test_routing_commit.py`、`tests/test_ui_proxy.js`、`tests/test_ui_proxy_rate.js`、`tests/test_ui_routing.js` 扩充覆盖。
