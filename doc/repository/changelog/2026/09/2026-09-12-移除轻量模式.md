# 移除轻量模式

- 日期：2026-09-12
- 功能：移除「轻量模式」设置与全部关联逻辑
- 分支：main

## 变更

- 自动化配置页删除「轻量模式」开关；`body.lightweight-mode` 全部 CSS 规则删除，动画与视觉效果不再受开关影响。
- 代理状态图形（流光）改为默认常显：未开启时代理轨道与流线/星光以慢速淡版循环，开启代理后切换为快速亮版；系统启用“减弱动画”时仅保留开启态的慢速指示。
- `core/config.py` 默认配置与 `config_maintenance.SAFE_CONFIG_FIELDS` 移除 `lightweight_mode`；历史配置中残留的该字段不再参与任何逻辑，用户数据中已存在的一次性清除。
- `api.py` 的 `UiStateStream` 采样间隔固定为 0.5 秒，删除按轻量模式切换间隔的分支；桌面设置返回值不再包含 `lightweight_mode`。
- `ui/app.js` 删除 `applyLightweightMode` 与开关绑定/回填逻辑；知识库文档同步修正。

## 验证

- 离线回归与 UI 静态测试更新后全部通过（`test_ui_polish.js` 中轻量模式断言已随功能移除）。
- 按仓库规则完成打包、配置保留核对与新版启动验证。
