# 域名分流导航与快捷键精简

- 日期：2026-09-12
- 功能：左侧导航新增「域名分流」入口、动画不再适配减弱动画、移除全局快捷键
- 分支：main

## 变更

- 左侧导航在「网络代理」下新增「域名分流」入口，直达统一分流页并默认打开「概览」页签；原「网络代理 → 高级分流」快捷入口保留。
- 删除全部 `prefers-reduced-motion` 适配规则（CSS 三段与节点定位的平滑滚动判断）；代理状态图形流光默认常显，动画节奏不再受系统“减弱动画”设置影响。
- 移除全局快捷键功能：总览页「全局快捷键」开关、`RegisterHotKey` 消息线程（`GlobalHotkeyManager`）、配置字段 `global_hotkeys_enabled` 及桌面设置返回字段全部删除；托盘菜单快捷操作不受影响。
- 配置变更记录中「托盘/快捷键…」来源标签改为「托盘…」。
- 修复：取消「关闭到托盘」后退出时托盘图标残留（主窗体先销毁导致托盤销毁被跳过），`DesktopController.dispose` 在线程内兜底清理；「关闭到托盘」说明文案补充“单击托盘图标恢复主窗口”。
- Codex 页面：`header h2` 内图标与文字间距统一（`.module-icon` 加 10px 间距）；`get_codex_status` 增加异常兜底并返回可展示的错误摘要，前端对缺失字段不再静默置空；本地视觉 QA mock（`build_tmp/qa-bootstrap.js`）补齐 Codex 状态/同步/还原/读取接口返回，浏览器预览不再出现空字段。

## 验证

- 离线回归与 UI 静态测试同步更新（导航按钮计数 13、快捷键断言移除）后全部通过。
- 按仓库规则完成打包、配置保留核对与新版启动验证。
