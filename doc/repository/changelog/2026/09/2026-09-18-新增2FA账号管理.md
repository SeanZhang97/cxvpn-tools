# 新增 2FA 账号管理

- 日期：2026-09-18
- 分支：main（工作区）
- 需求：按照用户确认的深色三列卡片设计实现各平台动态验证码管理，不增加分组、备注或收藏。

## 关键设计与涉及文件

- `ui/index.html`、`ui/two_factor.css`、`ui/two_factor.js`、`ui/app.js`：接入导航、搜索、验证码卡片/倒计时/复制、账号编辑菜单和备份弹窗；复用现有模态框、自定义下拉框、滚动条和密码可见性组件。Feather 图标及许可证位于 `ui/icons/feather/`。
- `core/two_factor.py`、`core/state_store.py`：新增独立账号表（schema 4）、DPAPI 加密、TOTP 生成、条目 revision 和事务导入；不改代理配置数据。
- `core/two_factor_api.py`、`api.py`：专用桥接与分阶段脱敏日志，不把密钥放入普通配置或全局状态。
- `core/two_factor_backup.py`：密码加密的 `.cx2fa` 备份，系统路径选择、原子保存、导入预览及冲突跳过；支持从备份恢复当前用户无法解密的条目。
- `core/two_factor_qr.py`、`main.py`：二维码图片/剪贴板导入，10 秒独立子进程解码边界，适配无控制台打包入口。
- `requirements-2fa.txt`：固定 PyOTP、cryptography、zxing-cpp 依赖版本。
- `tests/test_two_factor.py`、`tests/test_ui_two_factor.js`、`tests/test_ui_routing.js`、`tests/test_ui_polish.js`：算法、存储、加密、异常和 UI 契约回归。

## 影响范围与注意事项

- 密钥保存于同一 `%LOCALAPPDATA%/CXVPNTools/state.sqlite3`，自动升级只新增表，既有配置保持不变。
- 本机密钥绑定 Windows 用户；跨电脑通过密码加密备份迁移。HOTP 与 Google 批量迁移码不在支持范围。
- 验证码依赖系统时间；平台绑定仍由用户在对应平台完成。
- 验证码到期只刷新数字/进度，不重建卡片，避免关闭操作菜单或丢失焦点。
