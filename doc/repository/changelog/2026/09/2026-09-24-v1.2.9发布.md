# v1.2.9 发布

- 日期：2026-09-24
- 功能：发布 2FA 账号管理与首次安装开启代理修复
- 分支：`main`

## 发布内容

- 新增 2FA 账号管理：TOTP 动态验证码、DPAPI 加密存储（schema 4）、二维码/剪贴板
  导入、密码加密的 `.cx2fa` 备份与恢复，详见
  [2026-09-18-新增2FA账号管理](2026-09-18-新增2FA账号管理.md)。
- 修复首次安装（或从未成功应用过配置）的机器开启代理报
  "读取运行配置失败：系统找不到指定的文件"：路由服务 `status` 指令把运行配置
  缺失视为正常初始状态，详见
  [2026-09-24-修复首次安装开启代理报错](2026-09-24-修复首次安装开启代理报错.md)。

## 验证与产物

- routing-service `cargo test --release`：47 passed，含首装 status 回归用例。
- 2FA 离线回归、UI 静态检查与既有主库恢复测试沿用 09-18/09-20 记录结论。
- 使用 `build_release.py` 生成受保护核心、轻量安装器、便携 ZIP、SHA-256 文件和
  manifest；具体大小与摘要以 Release manifest 为准。
- Git tag：`v1.2.9`。

## 注意事项

- 本版本将用户主库 schema 升级到 4（仅新增 `otp_accounts` 表，幂等增量）；
  升级后不可回退到 1.2.8 及更早版本运行同一主库。
- 路由服务二进制更新，首次开启代理会按既有升级路径触发一次 UAC 重装服务。
- 未使用 Authenticode 产品证书签名时，Windows 可能显示未知发布者提示。
