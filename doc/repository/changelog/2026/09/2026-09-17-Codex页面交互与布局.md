## 问题与有效变更

- 实际窗口确认原设置卡片没有间距，代理控制位于底部而非对应配置附近。添加局部卡片间距、将代理按钮及反馈移到代理卡片，调整端口与路径列宽并允许窄窗口单列。
- 状态刷新会覆盖失焦后的地址草稿，密钥迟到响应也可能填回已清空的字段。使用独立草稿标记和读取序号保护用户输入，失败后保留草稿。
- 为配置写入和重启添加共享页面操作互斥，处理中禁用相关控件，状态读取失败禁用配置写入；异常后恢复可操作状态。
- 修复有效 API 配置被旧传输恢复提示遮盖的问题；简化密钥说明、补齐输入 label 关联，离开页面收起密钥明文。
- 还原确认明确说明原 Provider 恢复与历史任务统一同步的区别。应用已启动但历史同步失败时显示部分失败警告，保留后端原始告警含义。
- 将传输说明改为 HTTP/SSE，并说明加密取决于 HTTPS 地址，避免对明文 HTTP 自定义 API 作出加密承诺。
