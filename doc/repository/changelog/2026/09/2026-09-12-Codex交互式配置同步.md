# Codex 交互式配置同步

- 日期：2026-09-12
- 功能：Codex 代理配置的交互式同步、关闭与查看，及官方图标替换
- 分支：main

## 变更

- Codex 页面新增手动操作区：「开启 Codex 代理」（动态取当前 `routing.mixed_port`，不写死默认端口）、「关闭 Codex 代理」（删除本工具写入且未被手动修改的代理字段，用户手动改过的字段保留并提示）、「查看配置文件」（只读弹窗展示 config.toml 原文）。
- `core.codex_proxy` 新增 `read_config()`（只读返回原文，512KB 上限）与 `status()`（快照字段数、上次同步端口、偏离字段列表、无快照残留字段、解析错误），不返回或记录配置正文。
- 「关闭 Codex 代理」在快照缺失/丢失时按写入模式兜底删除（`http://127.0.0.1:<port>` 代理变量、默认 NO_PROXY、`respect_system_proxy=true`），避免旧版自动同步残留无法清除；状态页同步提示残留字段。
- 查看弹窗去除敏感值遮罩与工具栏按钮，直接展示原文，仅保留右上角叉号关闭。
- `api.py` 新增 `sync_codex_proxy`、`restore_codex_proxy`、`read_codex_config`，扩展 `get_codex_status` 包含快照状态摘要；手动操作不依赖代理是否启用，日志不含任何配置正文。
- Codex 图标替换为官方六片风叶形 mark（fill 图形），经 `.codex-nav-icon` 与 `.codex-module-icon` 覆写项目默认 stroke 风格；导航与页面头部图标同步更新。

## 影响与边界

- 自动链路保持不变：代理服务启动、系统代理激活、启动时代理有效即校正；代理关闭后按「关闭代理」语义删除托管字段（而非恢复原值）。同步目标仍为 `CODEX_HOME/config.toml`（未设置时 `%USERPROFILE%\.codex\config.toml`），快照位于 `%LOCALAPPDATA%\CXVPNTools\codex_proxy_snapshot.json`。该配置只影响读取这些环境变量的 Codex 进程；内置浏览器、插件独立进程与不继承 config.toml 的请求仍不受控制，配置变更后需要重启 Codex 才会生效。
