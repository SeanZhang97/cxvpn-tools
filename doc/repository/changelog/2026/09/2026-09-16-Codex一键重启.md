# Codex 一键重启

- 日期：2026-09-16
- 功能：在 Codex 页面确认后关闭 Codex、同步历史任务 Provider 并重新启动桌面应用
- 分支：`main`

## 需求概述

Codex 配置变化需要重启已运行的 Codex 才能生效。原页面只能提示用户手动操作，缺少直接重启入口。

## 涉及文件

- `core/codex_runtime.py`
- `api.py`
- `ui/index.html`
- `ui/app.js`
- `tests/test_codex_runtime.py`
- `tests/test_api_codex_proxy.py`
- `tests/test_ui_codex_transport.js`
- `doc/repository/knowledge/INDEX.md`
- `doc/repository/knowledge/modules/Codex代理配置同步.md`

## 关键设计

- Codex 页面新增「重启 Codex」按钮。执行前明确提示会关闭全部 Codex 窗口并中断运行中任务，用户确认后才提交。
- Windows 端按 `OpenAI.Codex` MSIX 安装目录识别 `ChatGPT.exe` 进程组，不按通用进程名结束，避免影响其他 ChatGPT 安装或无关同名进程。
- 先对具有主窗口的进程请求正常关闭，4 秒内未退出的包内进程再强制结束；确认全部退出后，通过 `OpenAI.Codex_2p2nqsd0c76g0!App` 对应的 AppsFolder 标识启动，并等待不带 `--type=` 的主进程出现。
- Codex 完全退出后调用历史任务 Provider 同步，再启动桌面应用；同步失败或出现意外异常时仍会执行启动，并返回部分失败。
- PowerShell 关闭和启动阶段合计限制为 35 秒，日志覆盖 UI 提交、领取、开始、目标与超时、成功或失败及耗时。PowerShell 使用 UTF-8 编码，异常不会无限阻塞 UI。

## 影响范围

- 进程控制只处理当前用户安装的 `OpenAI.Codex` 桌面应用。重启期间会备份并同步侧边栏可见根任务的 Provider 元数据；不修改 Codex 凭据、CXVPNTools 配置或 VPN 状态。
- 重启会中断 Codex 中正在运行的任务；确认弹窗已明确提示该影响。
