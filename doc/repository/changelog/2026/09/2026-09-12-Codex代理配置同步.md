# Codex 代理配置同步

- 日期：2026-09-12
- 功能：Codex 本机代理配置同步与左侧 Codex 入口
- 分支：main

## 变更

- 路由服务在 Windows 系统代理成功启用、mixed-port 变化成功应用以及启动时确认已有有效代理时，读取当前 `routing.mixed_port`，局部更新 Codex 用户 `config.toml`。
- 关闭代理后按字段快照恢复 cxvpn-tools 首次托管前的值；用户运行期间手动修改的字段保留并记录警告。
- 配置和快照均使用 UTF-8、临时文件、刷盘和原子替换；TOML 校验或写入失败不会覆盖原文件。快照位于 `%LOCALAPPDATA%\\CXVPNTools\\codex_proxy_snapshot.json`，不进入发行目录。
- 左侧新增 Codex 菜单和状态页，显示当前 mixed-port、配置是否存在和重启提示；不自动结束 Codex。

## 影响与边界

同步目标为 `CODEX_HOME/config.toml`，未设置 `CODEX_HOME` 时使用 `%USERPROFILE%\\.codex\\config.toml`。内置浏览器、插件独立进程或不继承 Codex 配置的请求仍不受该配置控制；TUN 接管模式也不能被描述为让所有请求强制经过 Codex 配置代理。

- `.venv\\Scripts\\python.exe -m py_compile core/codex_proxy.py core/routing.py api.py` 与 `node --check ui/app.js` 通过。
