# v1.3.0 发布

- 日期：2026-09-29
- 功能：VPN 连接状态前置为默认规则与活动连接悬停闪烁修复
- 分支：`main`

## 发布内容

- VPN 连接状态前置为默认规则：路由配置生成时按 VPN 实际连接状态解析出站，
  未连接的 VPN 出站直接落入物理直连，不再依赖逐请求的 `physical_fallback`
  回退代理组；新增 `RoutingVpnWorker` 后台监控（15 秒轮询、状态稳定 15 秒后
  在路由锁内复用 apply 事务热重载，失败遵循原事务回滚），VPN 断开或恢复后
  分流规则自动跟随切换。规则编辑界面移除物理回退开关。
- 修复总览页活动连接模块悬停开关按钮时每秒闪烁：`renderVpnConnections`
  从整表重建改为按 VPN 名称复用行元素并就地更新（标签与按钮签名缓存），
  悬停状态不再被周期刷新打断。

## 验证与产物

- 离线回归：routing 336、代理生命周期 194、检查更新与打包品牌 28 全部通过；
  16 个 UI 静态测试（含活动连接行复用断言）全部通过。
- 使用 `build_release.py` 生成受保护核心、轻量安装器、便携 ZIP、SHA-256 文件和
  manifest；具体大小与摘要以 Release manifest 为准。
- Git tag：`v1.3.0`。

## 注意事项

- 旧配置中规则的 `physical_fallback` 字段在本版本被忽略（无需迁移）；
  VPN 断开时对应规则的行为由新的连接状态前置逻辑接管，首次状态翻转后
  最多约 30 秒完成热重载。
- 路由服务二进制与数据结构无变化，无需重新安装服务。
- 未使用 Authenticode 产品证书签名时，Windows 可能显示未知发布者提示。
