# v1.2.4 发布

- 日期：2026-09-16
- 功能：发布 VPN 路由维护、代理生命周期恢复与配置维护版本
- 分支：`main`

## 发布内容

- 自动维护 VPN 目标路由，并在 VPN 未连接时保持物理网络直连；配套原生路由服务和定制 Mihomo 核心协同处理路由租约。
- 增加 Codex 模型传输一键切换，并修复补录凭据后的连接续接。
- 完善代理启停状态收敛、失败恢复、无效系统代理修复和运行态一致性检查。
- 支持每个订阅独立配置自动测速间隔，避免统一周期造成不必要的批量测速。
- 精简配置维护入口，补充配置导入导出及相关校验。
