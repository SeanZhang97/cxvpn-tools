# v1.2.1 发布

- 日期：2026-09-13
- 功能：发布代理关闭、TUN 事务与自动物理出口修复版本
- 分支：main（发布时提交全部本地改动）

## 发布内容

- 修复 Windows 系统代理快照为空或自引用本软件端口时的恢复异常。
- TUN active 时事务化暂停 Windows 手动代理与 PAC，提交前执行当前用户会话刷新和注册表回读，
  失败恢复上一份接管配置。
- 物理出口支持持久化自动选择，并在默认网卡稳定变化后复用完整事务自动切换。
- 首页按原生服务实际接管方式和配置签名展示运行状态，避免应用失败后误报已关闭。
- 补充 TUN 域名规则绑定 Windows VPN 的配置回归。
