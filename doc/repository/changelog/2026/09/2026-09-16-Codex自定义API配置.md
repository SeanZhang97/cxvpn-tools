# Codex 自定义 API 配置

- 日期：2026-09-16
- 功能：在 Codex 页面配置自定义模型 API 地址与 API Key，并支持安全还原
- 分支：`main`

## 需求概述

Codex 页面原有代理同步和 WSS / HTTPS-SSE 传输切换，但缺少自定义 OpenAI 兼容 Responses API 的配置入口。个人环境需要直接把地址和 API Key 写入 Codex 用户级 `config.toml`，同时能够恢复保存前的 Provider 选择。

## 关键设计

- 保存时只生成 `codex_local_access`，写入 `base_url`、`wire_api = "responses"`、`requires_openai_auth = true`、`supports_websockets` 与 `experimental_bearer_token`，根级 `model_provider` 同样指向该 ID。`requires_openai_auth` 保留 Codex 的 ChatGPT 登录身份，模型请求的 `Authorization` 仍由 `experimental_bearer_token` 提供。
- 保存自定义 API 不修改内置 `openai` 或其他 Provider，也不在保存阶段改写历史任务。原根级 Provider 为 `openai` 时，还原后继续恢复为 `openai`；用户另行确认「重启 Codex」时，侧边栏可见根任务会同步到重启时的当前 Provider。
- 界面明确说明左下角继续保留 ChatGPT 登录身份，模型请求使用自定义 API；旧版受托管配置缺少 `requires_openai_auth` 时提示再次保存升级。
- 「优先 WSS」对应 `codex_local_access.supports_websockets`，自定义 API 模式下只修改这一处。
- API Key 首次保存必填；界面使用密码输入与显隐按钮，保存后重新读取当前受托管配置并以密码形式显示。
- 已保存的 API 地址和 API Key 同时写入 SQLite 主配置的 `codex_api`；API Key 不复制到兼容 `config.json`、配置导出、通用 UI 配置响应或日志。页面通过独立本机接口优先从 SQLite 回显；升级后尚未入库时，从仍受托管的 Codex Provider 读取一次并迁移。
- 「还原原配置」只恢复 Codex `config.toml`，不修改 SQLite 中的地址和 API Key；还原后仍可直接再次保存并启用。
- 新增独立恢复记录 `codex_api_snapshot.json`。当前自定义 API Key 不以明文写入恢复记录，只保存密钥 SHA-256；为精确还原保存前已有的 `codex_local_access`，恢复记录在本机保存该 Provider 的原始完整 table。
- 写入继续使用 TOML 解析校验、写前回读、原子替换和 `prepared/committed` 两阶段记录。还原会恢复未被手动修改的原 `codex_local_access`，或在原先不存在时删除；用户修改过的根级选择或 Provider 内容保持不变并给出警告。
- 兼容早期单 `codex_local_access` 与过渡期双 Provider 两种版本 1 恢复记录：按记录结构选择对应的 Provider 字段和密钥摘要进行校验，匹配时恢复回显、重新保存及 WSS 修改并升级为版本 2。双 Provider 的旧别名已删除但 `codex_local_access` 仍精确匹配时，也视为可安全继续的半迁移状态；真实内容冲突或无可信恢复记录的同名 Provider 仍不自动覆盖。
- 保存自定义 API 时会先校验并自动结束既有 `cxvpn_openai_http` 恢复事务：专用 Provider 未被手动修改时自动清理；当前仍选中专用 Provider 时先恢复原选择，当前已由用户切到其他 Provider 时保留该选择。无需先手动开启「优先 WSS」，两份快照也不会交叉覆盖根级 `model_provider`。
- 修正根级 Provider 已恢复或已切到其他 Provider、但旧传输 Provider 与快照仍存在时被误判为不可操作的问题；状态接口会明确返回可恢复与待清理状态，WSS 开关可直接完成恢复或清理。
- 统一 Codex 页面文案为“当前状态 + 操作影响”的表达：传输区域明确显示“当前 Provider”，代理与自定义 API 区域隐藏快照、事务和托管字段等内部实现术语，并精简重启与影响范围提示。
- 状态接口只返回地址、是否配置密钥和事务摘要；日志不记录 API 地址正文、API Key 或配置正文。

## 影响范围

- 仅修改 Codex 用户级 `config.toml` 与 CXVPNTools 用户数据目录中的恢复记录，不修改 `auth.json`、VPN 配置或软件代理状态。
- 保存或还原后，已运行的 Codex 仍需重启才能重新加载配置。

## 注意事项

- API Key 按用户选择以明文形式存在于 Codex 用户级 `config.toml`；恢复记录、状态接口、测试和日志均不保存或回显真实密钥。
- 本功能不主动请求自定义 API，也不验证远端模型可用性；这里只负责配置写入、状态显示与可恢复还原。
- 本机使用 Codex CLI `0.155.0-alpha.2.6` 和一次性回环假 API 验证：同时配置 `requires_openai_auth = true` 与 `experimental_bearer_token` 时，认证状态保持为 ChatGPT auth，模型请求实际发送自定义 bearer；探针未记录令牌原文，也未访问真实模型服务。
