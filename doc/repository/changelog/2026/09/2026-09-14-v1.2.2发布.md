# v1.2.2 发布

- 日期：2026-09-14
- 功能：发布路由服务与打包重启恢复版本
- 分支：`main`

## 发布内容

- 修复原生路由服务卡在 `START_PENDING` 时的受控终止、删除确认和回滚边界。
- 打包前后核对 LocalAppData SQLite 与兼容 JSON 摘要，并只启动本次构建产物。
- 防止旧便携配置覆盖已建立的 SQLite 权威状态，并为兼容配置增加恢复历史。
- 校正开机启动路径，启动复核时保留第三方系统代理。
- 设置页改为字段级提交，拒绝旧页面以过期整包配置覆盖凭据、授权和路由状态。
