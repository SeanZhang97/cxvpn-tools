# v1.3.1 发布

- 日期：2026-09-29
- 功能：升级下载实时读取系统代理与升级守卫夹具测试修复
- 分支：`main`

## 发布内容

- 升级下载实时读取系统代理：升级包下载与检查更新统一改走每次调用实时重建的
  opener（`ProxyHandler()` 构造时读取当前系统代理），修复进程级全局 opener 在
  首次 urlopen 时固化代理配置、之后开启系统代理也不生效导致的下载升级包
  URLError；网络层错误最多 3 次重试、末次直连兜底、隧道被拒立即转直连，
  失败文案带具体原因。详见《2026-09-29-升级下载实时读取系统代理》。
- 升级守卫夹具测试修复：`UpdateGuardFixtureTests` 不再 mock `Get-FileHash`
  （PS 5.1 中它是 Microsoft.PowerShell.Utility 的模块高级函数，外层脚本定义的
  同名函数无法覆盖守卫子脚本内的调用），改为真实 fixture.exe 文件与真实
  SHA-256；`Test-Path` mock 对带 `-PathType` 的调用用模块限定名回退真实
  cmdlet，避免 Get-FileHash 内部的目录排除检查被 mock 短路。

## 验证与产物

- 离线回归：routing 336、代理生命周期 194、检查更新与打包品牌 65（含修复后的
  守卫 9 场景）全部通过；16 个 UI 静态测试全部通过。
- 使用 `build_release.py` 生成受保护核心、轻量安装器、便携 ZIP、SHA-256 文件和
  manifest；具体大小与摘要以 Release manifest 为准。
- Git tag：`v1.3.1`。

## 注意事项

- `core/ip_info.py`、`core/captcha_handler.py` 仍有裸 `urllib.request.urlopen`
  调用，同样受全局 opener 代理固化影响；本次未改动，后续如遇类似问题按同一
  模式处理。
- 路由服务二进制与数据结构无变化，无需重新安装服务。
- 未使用 Authenticode 产品证书签名时，Windows 可能显示未知发布者提示。
