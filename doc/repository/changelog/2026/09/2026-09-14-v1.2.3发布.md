# v1.2.3 发布

- 日期：2026-09-14
- 功能：修复升级后窗口显示旧版页面（WebView2 缓存）
- 分支：`main`

## 发布内容

- 修复 pywebview 内置 HTTP 服务器丢失 no-cache 响应头的问题：bottle `static_file` 返回的独立响应会整体替换线程本地响应头，导致 WebView2 按启发式策略缓存旧版 HTML/CSS/JS，升级后窗口不显示新菜单、页面布局退化。
- 新增 `core/ui_cache.py` 两层防护：包装 `bottle.static_file` 补回 `Cache-Control: no-cache, no-store, must-revalidate` 与 `Pragma: no-cache`；按 `webview_data/ui-cache-version.txt` 版本标记在启动时清理 WebView2 的 HTTP 缓存（仅 `Cache` 与 `Code Cache`，不触碰 Cookie/本地存储等登录态）。
- 清理结果写入 startup.log，便于现场判断是否触发过缓存清理。

- 未使用 Authenticode 签名时，Windows 可能显示未知发布者提示。
