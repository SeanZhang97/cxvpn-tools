# v1.2.5 发布

- 日期：2026-09-17
- 功能：发布 Codex 自定义 API、历史任务同步及页面交互修正
- 分支：main

## 发布内容

- 自定义 API 使用单一 `codex_local_access` Provider；保留 ChatGPT 登录身份，模型请求使用自定义 API Key。
- 地址和密钥保存在 SQLite 主库，密钥不进入兼容 JSON、通用配置响应或日志；支持还原原 Provider。
- 确认重启 Codex 时备份并同步可见根任务的 Provider，支持账号/API 双向切换、异常回滚及任务筛选。
- Codex 页面改善布局、草稿保护、请求互斥、状态回读、还原说明和部分失败反馈。
- `core/version.py` 升至 1.2.5；受保护构建从该唯一版本来源生成 EXE 版本资源，使 Inno Setup 安装器能够校验受保护目录包。

## 涉及文件

- `api.py`、`core/codex_proxy.py`、`core/codex_runtime.py`、`core/codex_session_provider.py`、`core/config.py`、`core/version.py`。
- `ui/app.js`、`ui/index.html`、`ui/style.css` 及相关回归测试。
- `build_protected.py`、`tests/test_build_branding.py`；各功能详细记录见同目录 Codex 相关 changelog。

## 验证与限制

- Python 语法检查通过；Codex、状态存储、版本升级和构建生命周期相关测试 149 项通过。
- Node 语法、Codex UI 交互与全局样式/组件静态回归通过。
- 路由离线回归 293 项中 292 项通过；`test_apply_allows_unused_manual_provider_without_snapshot` 被本机 Windows 手动代理回读不一致阻断，该调用链不经过 Codex 逻辑。未修改系统代理设置以规避该结果。
- 本机实际窗口检查配置区、表单和还原确认框；未执行真实 API 请求、Codex 重启或历史迁移。
- 安装器前置依赖执行器 5 个离线场景通过；WebView2 与 VC++ 离线依赖的 Microsoft 签名、大小与 SHA-256 校验通过。
- 待提交文件扫描未发现高置信度密钥或私钥；用户配置、数据库、依赖缓存和构建产物不纳入源码提交。
- 安装、覆盖升级、卸载和真实账号/API 往返由用户实机验收，不将离线或窗口检查等同于完整端到端测试。
