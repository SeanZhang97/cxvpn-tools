# v1.2.8 发布

- 日期：2026-09-17
- 功能：发布升级完成自动重启修复版本
- 分支：`main`

## 发布内容

- 修复应用内升级完成后软件未自动重启的问题。
- 安装器仅在应用内升级携带专用参数时，以原桌面用户启动新版；普通静默安装保持不自动打开应用。
- 非提权升级守护等待安装器真实退出，校验退出码、注册表和 EXE 版本，再按完整路径复核新版进程。
- 安装器未能启动新版时由守护兜底拉起；安装器已启动时不重复启动，并统一校验进程持续存活5秒。

## 验证与产物

- Python 语法检查、更新器/API升级桥接回归及路由离线回归通过。
- Inno Setup 编译、构建锁校验与打包EXE用户数据探针通过。
- 使用 `build_release.py` 生成受保护轻量安装器、便携ZIP、SHA-256文件和manifest；具体大小与摘要以Release manifest为准。
- Git tag：`v1.2.8`。

## 注意事项

- 未使用 Authenticode 产品证书签名时，Windows 可能显示未知发布者提示。
- 用户数据继续使用 `%LOCALAPPDATA%\CXVPNTools` 中的SQLite主库；发行产物不得包含配置、凭据、日志或恢复备份。
- 本轮未执行覆盖当前安装目录的真实升级、卸载或系统重启恢复测试。
